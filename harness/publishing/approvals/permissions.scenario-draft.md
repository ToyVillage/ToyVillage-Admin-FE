# Scenario Draft — permissions

출처: `harness/publishing/specs/permissions.spec.md` (행동명세가 source of truth)
상태: 승인 (2026-11-03, S17 페이지네이션은 개발자 결정으로 제외. 번호는 승인 때 본 그대로 유지)

> 초기 mock: 중간 관리자 3명(김수인·이승현·이지아), 지정 가능 직원 5명(박도현·최민지·정하윤·오세훈·한지민). 새로고침하면 초기값으로 돌아간다.
> 날짜 기대값은 테스트 시작 시 고정한 브라우저 시계(예: 2026-11-03)를 기준으로 계산한다.
> 실패 토스트는 mock 이 실패하지 않아 여기서 다루지 않는다. `/api` 연동 때 시나리오를 더한다.

## 핵심 시나리오

### S1: 사이드바에서 권한 관리 진입
- Given: 로그인한 관리자가 대시보드에 있다.
- When: 사이드바 `설정` > `권한 관리`를 클릭한다.
- Then: `/settings/permissions`로 이동하고 `권한 관리` 제목(h1)과 부제 `토이빌리지 중간 관리자 지정 및 해제`, `중간 관리자 지정` 버튼이 보인다. 사이드바의 `권한 관리` 항목이 활성이다.

### S2: 첫 진입 목록
- Given: 초기 mock 상태다.
- When: `/settings/permissions`에 들어온다.
- Then: 머리행 `이름` / `지정일` 아래에 김수인 `suin.kim` `2026.07.03`, 이승현 `seunghyun.lee` `2026.09.01`, 이지아 `jia.lee` `2026.10.20` 순서로 3행이 보이고, 행마다 `해제` 버튼이 있으며 `총 3명`이 보인다. 페이지네이션은 없다.

### S3: 목록 검색
- Given: 첫 진입 상태다.
- When: 검색 입력에 `SEUNG`을 넣는다.
- Then: 이승현 1행만 남고 `총 1명`이며 URL에 `keyword=SEUNG`이 붙는다.
- When: 새로고침한다.
- Then: 같은 검색어와 결과가 유지된다.

### S4: 지정 모달 기본 상태
- Given: 첫 진입 상태다.
- When: `중간 관리자 지정` 버튼을 클릭한다.
- Then: 제목 `중간 관리자 지정`과 부제 `중간 관리자로 지정할 직원을 선택하세요`인 모달이 열리고 검색 입력에 포커스가 있다. 박도현·최민지·정하윤·오세훈·한지민 5명이 모두 미선택이고 김수인·이승현·이지아는 없다. `지정하기` 버튼은 비활성이다.

### S5: 직원 선택과 버튼 문구
- Given: 지정 모달이 열려 있다.
- When: 박도현 행과 최민지 행을 클릭한다.
- Then: 두 행의 체크박스가 켜지고 버튼이 `2명 지정하기`로 바뀌며 활성이다.
- When: 최민지 행을 다시 클릭한다.
- Then: 버튼이 `1명 지정하기`다.
- When: 박도현 행을 다시 클릭한다.
- Then: 버튼이 `지정하기`로 돌아가 비활성이다.

### S6: 지정 완료
- Given: 지정 모달에서 박도현과 최민지를 선택했다. 오늘은 2026-11-03이다.
- When: `2명 지정하기`를 클릭한다.
- Then: 모달이 닫히고 토스트 `권한 부여에 성공했습니다`가 뜬다. 목록 맨 아래에 박도현 `2026.11.03`, 최민지 `2026.11.03` 순서로 2행이 붙고 `총 5명`이다.

### S7: 모달 검색과 선택 유지
- Given: 지정 모달이 열려 있다.
- When: 박도현을 선택하고 모달 검색 입력에 `sehun`을 넣는다.
- Then: 오세훈 1행만 보이고 버튼은 `1명 지정하기`다.
- When: 오세훈을 선택한 뒤 검색어를 지운다.
- Then: 5명이 다시 보이고 박도현·오세훈이 선택되어 있으며 버튼은 `2명 지정하기`다.

### S8: 지정 모달 닫기
- Given: 지정 모달에서 박도현을 선택하고 검색어를 넣었다.
- When: `취소`를 클릭한다.
- Then: 모달이 닫히고 목록은 그대로 `총 3명`이며 포커스가 `중간 관리자 지정` 버튼으로 돌아간다.
- When: 모달을 다시 열고 `Escape`를 누른다.
- Then: 모달이 닫힌다.
- When: 모달을 다시 열고 딤 바깥을 클릭한다.
- Then: 모달이 닫힌다.
- When: 모달을 다시 연다.
- Then: 검색어와 선택이 비어 있다.

### S9: 해제 확인 모달
- Given: 첫 진입 상태다.
- When: 김수인 행의 `해제`를 클릭한다.
- Then: 제목 `중간 관리자를 해제하시겠습니까?`, 설명 `해제하면 김수인님은 직원 권한으로 돌아갑니다`, `취소`·`해제` 버튼이 있는 확인 모달이 열린다.

### S10: 해제 취소
- Given: 김수인의 해제 확인 모달이 열려 있다.
- When: `취소`를 클릭한다.
- Then: 모달이 닫히고 김수인 행이 그대로이며 `총 3명`이고, 포커스가 김수인 행의 `해제` 버튼으로 돌아간다.
- When: 다시 열고 `Escape`를 누른다.
- Then: 같은 결과다.

### S11: 해제 완료
- Given: 김수인의 해제 확인 모달이 열려 있다.
- When: `해제`를 클릭한다.
- Then: 모달이 닫히고 토스트 `권한 해제에 성공했습니다`가 뜨며, 김수인 행이 사라지고 이승현·이지아 2행과 `총 2명`이 보인다.

## 엣지 케이스

### S12: 지정·해제가 후보 목록에 반영된다
- Given: 첫 진입 상태에서 박도현을 지정하고 김수인을 해제했다.
- When: 지정 모달을 연다.
- Then: 김수인이 후보에 있고 박도현은 후보에 없다.

### S13: 모두 해제하면 빈 상태
- Given: 첫 진입 상태다.
- When: 3명을 차례로 해제한다.
- Then: `지정된 중간 관리자가 없어요`와 `중간 관리자 지정 버튼으로 직원을 지정해 보세요`가 보이고, `총 0명`은 보이지 않는다. `중간 관리자 지정` 버튼과 검색 입력은 그대로 있다.

### S14: 목록 검색 결과 없음
- Given: 첫 진입 상태다.
- When: 검색 입력에 `없는사람`을 넣는다.
- Then: `검색결과가 없습니다`와 `총 0명`이 보이고, 빈 상태 문구 `지정된 중간 관리자가 없어요`는 보이지 않는다.

### S15: 모달 검색 결과 없음
- Given: 지정 모달이 열려 있고 박도현을 선택했다.
- When: 모달 검색 입력에 `없는사람`을 넣는다.
- Then: 목록 자리에 `검색결과가 없습니다`가 보이고 버튼은 `1명 지정하기`다.

### S16: 지정할 수 있는 직원이 없음
- Given: 첫 진입 상태에서 후보 5명을 모두 지정했다.
- When: 지정 모달을 연다.
- Then: 목록 자리에 `지정할 수 있는 직원이 없습니다`가 보이고 `지정하기` 버튼은 비활성이다.

### S18: 키보드로 모달 조작
- Given: 지정 모달이 열려 있고 검색 입력에 포커스가 있다.
- When: `Tab`으로 첫 직원 체크박스로 옮겨 `Space`를 누른다.
- Then: 박도현이 선택되고 버튼이 `1명 지정하기`다.
- When: 모달의 마지막 버튼에서 `Tab`을 누른다.
- Then: 포커스가 모달 밖으로 나가지 않고 모달의 첫 요소로 돌아간다.
