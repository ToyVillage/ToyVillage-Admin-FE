# Scenario Draft — dashboard

출처: `harness/publishing/specs/dashboard.spec.md` (행동명세가 source of truth)
상태: draft (게이트 승인 전)

## 핵심 시나리오

### S1: 대시보드 기본 렌더
- Given: 로그인한 관리자, 대시보드 mock 데이터(Figma 값)
- When: `/` 에 진입한다
- Then: `대시보드` 제목, KPI 카드 4개(`먹이 급여 기록 3` · `개체 관리 12` · `업무보고 3` · `작성된 일지 9`), 섹션 카드 6개(`휴관일 관리` · `전체 업무` · `먹이 급여 관리` · `개체관리` · `업무보고` · `업무일지관리`)가 보인다

### S2: 이번주 chip
- Given: 오늘이 2026-09-03(목)으로 고정돼 있다
- When: `/` 에 진입한다
- Then: `이번주 · 2026.08.30 ~ 09.05` 가 보인다

### S3: KPI 카드 이동
- Given: 대시보드가 렌더돼 있다
- When: 각 KPI 카드를 클릭한다
- Then: `먹이 급여 기록` → `/feeds`, `개체 관리` → `/species`, `업무보고` → `/task-reports`, `작성된 일지` → `/work-logs` 로 이동한다

### S4: 섹션 카드 이동
- Given: 대시보드가 렌더돼 있다
- When: 각 섹션 카드(자세히 보기)를 클릭한다
- Then: `휴관일 관리` → `/notices/guide`, `전체 업무` → `/tasks`, `먹이 급여 관리` → `/feeds`, `개체관리` → `/species`, `업무보고` → `/task-reports`, `업무일지관리` → `/work-logs`

### S5: 키보드로 카드 이동
- Given: 대시보드가 렌더돼 있다
- When: KPI 카드에 초점을 두고 Enter 를 누른다
- Then: 해당 화면으로 이동한다

### S6: 전체 업무 집계
- Given: 완료 15 · 진행중 9 · 지연 6
- When: `/` 에 진입한다
- Then: 도넛 가운데 `30`, 범례에 `완료 15` · `진행중 9` · `지연 6` 이 보인다

### S7: 휴관일 표시
- Given: 이번 달에 휴관일 3건(하루 2건, 이틀 연속 1건)이 있다
- When: `/` 에 진입한다
- Then: 달력 헤더가 `YYYY년 MM월`(이번 달)이고, 휴관 날짜 칸이 휴관일로 강조되며, 목록에 `M월 D일` / `M월 D일 ~ M월 D일` 형식과 사유가 시작일 순으로 보인다

### S8: 최근 목록 카드 내용
- Given: 대시보드 mock 데이터
- When: `/` 에 진입한다
- Then: 먹이 급여 카드에 `표범 · 레오` + `2026.09.03 09:30`, 업무보고 카드에 보고 제목 + 심사 상태 배지(`심사대기`/`완료`/`반려`), 업무일지 카드에 `마감일지` + `김수인` 이 보인다

## 엣지 케이스

### S9: 로딩
- Given: 대시보드 조회가 지연된다
- When: `/` 에 진입한다
- Then: `불러오는 중` status(`aria-busy=true`) 스켈레톤이 보이고 `대시보드를 불러오는 중입니다.` 문구는 보이지 않는다 (`loading-skeleton-list` 반영)

### S10: 조회 실패
- Given: 대시보드 조회가 실패한다
- When: `/` 에 진입한다
- Then: `대시보드를 불러오지 못했습니다.` 가 보인다

### S11: 빈 데이터
- Given: 모든 목록이 비어 있고 업무 합계가 0 이다
- When: `/` 에 진입한다
- Then: 각 카드에 빈 문구(`이번 달 휴관일이 없습니다.` · `최근 먹이 급여 기록이 없습니다.` · `최근 관찰 기록이 없습니다.` · `최근 업무보고가 없습니다.` · `최근 업무일지가 없습니다.`)가 보이고, 도넛 가운데 `0` 이 보인다

### S12: 긴 텍스트 말줄임
- Given: 업무보고 제목이 카드 폭보다 길다
- When: `/` 에 진입한다
- Then: 제목이 한 줄로 잘리고 심사 상태 배지는 카드 안에 온전히 보인다
