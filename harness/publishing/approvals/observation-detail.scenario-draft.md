## 핵심 시나리오

### S1: 상세 진입 기본 표시
- Given: 관찰 `1` 상세 경로 `…/1`
- When: 화면에 진입한다
- Then: `뒤로가기`, 제목 `얼굴 콧잔등 부위 약 3cm 긁힌 상처 있음`, 날짜 `2026.06.01`, 관찰자 `김유영`,
  `관찰사항` 카드(관찰사항 본문), `첨부` 카드가 보인다

### S2: 첨부 전체 표시
- Given: 첨부가 3개인 관찰 `1` 상세
- When: `첨부` 카드를 확인한다
- Then: `상처사진.jpg`·`상처사진_측면.jpg`·`처치기록.pdf` 칩 3개가 모두 보이고 `외 N개` 표기는 없으며, 각 칩에 `{파일명} 다운로드` 버튼이 있다

### S3: 첨부 다운로드
- Given: 관찰 `1` 상세
- When: `상처사진.jpg 다운로드` 버튼을 클릭한다
- Then: 파일명이 `상처사진.jpg` 인 파일이 내려받아진다

### S4: 뒤로가기
- Given: 관찰 `1` 상세
- When: `뒤로가기` 를 클릭한다
- Then: 확인 없이 개체 상세 `/species/1/individuals/1` 로 이동한다

### S5: 케밥 메뉴 열기
- Given: 관찰 `1` 상세
- When: 제목 행 우측 `⋮` 를 클릭한다
- Then: `수정` / `삭제` 두 항목이 보인다

### S6: 케밥 수정 → 수정 화면 이동
- Given: 케밥 메뉴가 열려 있음
- When: `수정` 을 클릭한다
- Then: `…/1/edit` 로 이동한다

### S7: 케밥 삭제 → 확인 모달
- Given: 케밥 메뉴가 열려 있음
- When: `삭제` 를 클릭한다
- Then: 메뉴가 닫히고 `정말 삭제하시겠습니까?` 확인 모달이 열린다

### S8: 삭제 확인 → 개체 상세 이동
- Given: 관찰 `1` 상세에서 삭제 확인 모달이 열려 있음
- When: `확인` 을 클릭한다
- Then: `/species/1/individuals/1` 로 이동하고 `데이터 삭제에 성공했습니다` 토스트가 뜨며, 관찰 기록 표에서 그 관찰 행이 사라진다

## 엣지 케이스

### S9: 첨부 없음
- Given: 첨부가 없는 관찰 `3`
- When: `…/3` 로 진입한다
- Then: `첨부` 카드는 보이고 칩 자리에 `—` 가 보인다

### S10: 케밥 메뉴 닫기
- Given: 케밥 메뉴가 열려 있음
- When: 메뉴 바깥을 클릭하거나 `Escape` 를 누른다
- Then: 메뉴가 닫히고, `Escape` 로 닫은 경우 초점이 `⋮` 로 돌아온다

### S11: 삭제 취소
- Given: 삭제 확인 모달이 열려 있음
- When: `취소` 를 클릭한다
- Then: 모달이 닫히고 관찰 상세 화면이 그대로 남으며 초점이 `⋮` 로 돌아온다

### S12: 삭제 실패
- Given: 삭제가 실패하는 조건(e2e 가짜 서버 `failNext('observation.delete')`)에서 삭제 확인 모달이 열려 있음
- When: `확인` 을 클릭한다
- Then: 모달이 닫히고 관찰 상세 화면에 `데이터 삭제에 실패했습니다` 토스트가 뜨며 화면이 유지된다

### S14: 없는 관찰 기록
- Given: 존재하지 않는 관찰 id
- When: `…/9999` 로 진입한다
- Then: `관찰 기록을 찾을 수 없습니다.` 와 `개체 상세로 돌아가기` 링크(`/species/1/individuals/1`)가 보인다

### S15: 다른 개체 경로의 관찰 id
- Given: 관찰 `1` 은 개체 `1` 의 기록이다
- When: `/species/1/individuals/2/observations/1` 또는 `/species/2/individuals/1/observations/1` 로 진입한다
- Then: S14 와 같이 `관찰 기록을 찾을 수 없습니다.` 와 개체 상세 복귀 링크가 보인다

### S16: 키보드 조작
- Given: 관찰 `1` 상세
- When: 키보드만으로 뒤로가기 포커스, 케밥 열기·메뉴 항목 실행, 다운로드 버튼 실행을 시도한다
- Then: 모든 조작이 가능하고 포커스 표시가 outline 으로 보인다
