# Scenario Draft — attachment-preview

출처: `harness/publishing/specs/attachment-preview.spec.md` (yot `2435:24604`, `2435:24629`)
상태: draft — 개발자 승인 대기

## 핵심 시나리오

### S1: 이미지 미리보기
- Given: 이미지 첨부(png)가 있는 업무 상세 화면, 파일 서버가 이미지를 돌려준다
- When: 첨부의 `<파일명> 미리보기` 버튼 클릭
- Then: 이름이 파일명인 dialog 가 열리고, 그 안에 alt 가 파일명인 이미지가 보인다

### S2: PDF 미리보기와 페이지 이동
- Given: PDF 첨부(3쪽)가 있는 업무 상세 화면, 파일 서버가 3쪽 PDF 를 돌려준다
- When: `<파일명> 미리보기` 클릭
- Then: dialog 에 `1 / 3` 이 보이고 `이전 페이지` 는 비활성이다
- When: `다음 페이지` 를 두 번 클릭
- Then: `3 / 3` 이 보이고 `다음 페이지` 는 비활성이다
- When: `이전 페이지` 클릭
- Then: `2 / 3` 이 보인다

### S3: 모달에서 내려받기
- Given: S1 의 미리보기 모달이 열려 있다
- When: 모달의 `다운로드` 클릭
- Then: 원래 파일명으로 내려받아지고 dialog 는 계속 열려 있다

### S4: 모달 닫기
- Given: 미리보기 모달이 열려 있다
- When: `닫기` 클릭 / `Escape` / 어두운 배경 클릭 (각각)
- Then: dialog 가 사라지고 초점이 `<파일명> 미리보기` 버튼에 있다

### S5: 공지사항·업무보고 상세에서도 열림
- Given: 이미지 첨부가 있는 공지사항 상세, 업무보고 상세
- When: 각 화면에서 `<파일명> 미리보기` 클릭
- Then: 파일명 dialog 가 열린다

## 엣지 케이스

### S6: 미리보기 불가 형식은 바로 내려받기
- Given: hwp(또는 xlsx) 첨부가 있는 업무 상세
- When: 그 첨부의 파일명 버튼 클릭
- Then: dialog 없이 원래 파일명으로 내려받아진다

### S7: 다운로드 아이콘은 그대로 (회귀)
- Given: 이미지 첨부가 있는 업무 상세
- When: `<파일명> 다운로드` 클릭
- Then: dialog 없이 내려받아진다

### S8: 파일 서버 실패
- Given: 파일 서버가 403 을 돌려준다
- When: `<파일명> 미리보기` 클릭
- Then: dialog 안에 `미리보기를 불러오지 못했습니다.` 가 보이고, 로그아웃되지 않고 상세 화면에 머문다
