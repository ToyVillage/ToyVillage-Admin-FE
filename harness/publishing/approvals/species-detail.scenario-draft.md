# Scenario Draft — species-detail

데이터 전제: 개체 mock(이 spec 소유, 26건) — 종 1 카피바라 3마리(동식이·미미·두리), 종 2 플라밍고 12마리(수컷·암컷·미상 포함,
법정지정분류·세부분류 없음), 종 3 반달가슴곰 2마리(법정지정분류 2개), 종 4~12 각 1마리, 종 13 피라냐 0마리(`species-list` 종 mock).
종 1 세부 분류는 `설치목 - 천축서과` 다. 개체 표 기본 정렬은 최신순(id 큰 순)이다.

## 핵심 시나리오

### S1: 종 상세 진입 기본 상태
- Given: 종 상세 라우트 `/species/1`
- When: 화면에 진입한다
- Then: `뒤로가기`, 제목 `카피바라`, 부제 `포유류 · Hydrochoerus hydrochaeris`, 정보 라벨 `국명` `분류군` `영문명` `학명` `법정지정분류` `세부분류`,
  섹션 헤더 `개체 3마리`, 표 3행이 최신순 `두리` → `미미` → `동식이` 순서로 보인다

### S2: 개체 표 컬럼과 값
- Given: `/species/1` 화면
- When: 개체 표를 확인한다
- Then: 헤더가 `이름` `성별` `출생연도` 이고, 1행이 `두리` / `수컷` / `2021년` 이다

### S3: 성별 뱃지 3종
- Given: 성별이 수컷·암컷·미상인 개체가 섞인 종 2
- When: `/species/2` 에 진입해 성별 열을 확인한다
- Then: `수컷` / `암컷` / `미상` 뱃지가 텍스트로 구분돼 보인다

### S4: 법정지정분류 여러 개
- Given: 법정지정분류가 2개인 종 3
- When: `/species/3` 에 진입한다
- Then: `법정지정분류` 값에 `멸종위기 야생생물 I급` / `천연기념물` 뱃지 두 개가 보인다

### S5: 뒤로가기
- Given: `/species/1` 화면
- When: `뒤로가기` 를 클릭한다
- Then: 확인 없이 `/species` 로 이동한다

### S6: 개체 등록하기 이동
- Given: `/species/1` 화면
- When: `개체 등록하기` 를 클릭한다
- Then: `/species/1/individuals/create` 로 이동한다

### S7: 행 본문 클릭 → 개체 상세
- Given: `/species/1` 화면
- When: `동식이` 행의 본문(케밥 밖)을 클릭한다
- Then: `/species/1/individuals/1` 로 이동한다

### S8: 개체명 검색
- Given: `/species/1` 화면
- When: 검색바에 `미미` 를 입력한다
- Then: `미미` 행만 남고, 섹션 헤더는 `개체 3마리` 그대로다

### S9: 페이지네이션 이동
- Given: 개체가 12마리인 종 2 의 `/species/2` 화면
- When: `2 페이지` 버튼을 클릭한다
- Then: 1페이지 10행이 남은 2행으로 바뀐다

### S10: 카드 케밥 메뉴 열기
- Given: `/species/1` 화면
- When: 프로필 카드 우상단 `⋮` 를 클릭한다
- Then: `수정` / `삭제` 두 항목이 보인다

### S11: 카드 케밥 `수정` → 종 수정 이동
- Given: 카드 케밥 메뉴가 열려 있음
- When: `수정` 을 클릭한다
- Then: 메뉴가 닫히고 `/species/1/edit` 로 이동한다

### S12: 카드 케밥 `삭제` → 종 삭제 확인 모달
- Given: 카드 케밥 메뉴가 열려 있음
- When: `삭제` 를 클릭한다
- Then: 메뉴가 닫히고 제목 `정말 삭제하시겠습니까?`, 본문 `등록된 개체와 관찰 기록도 함께 삭제되며` / `삭제 후에는 복구할 수 없습니다` 인 모달이 열린다

### S13: 종 삭제 확인 → 종 목록 이동
- Given: 종 삭제 확인 모달이 열려 있음
- When: `확인` 을 클릭한다
- Then: `/species` 로 이동하고 `데이터 삭제에 성공했습니다` 토스트가 뜬다

### S14: 행 케밥 메뉴 열기
- Given: `/species/1` 화면
- When: `동식이` 행 우측 `⋮` 를 클릭한다
- Then: 그 행의 `수정` / `삭제` 메뉴가 열리고 행 이동은 일어나지 않는다

### S15: 행 케밥 `수정` → 개체 수정 이동
- Given: `동식이` 행 케밥 메뉴가 열려 있음
- When: `수정` 을 클릭한다
- Then: 메뉴가 닫히고 `/species/1/individuals/1/edit` 로 이동한다

### S16: 행 케밥 `삭제` → 개체 삭제 확인 모달
- Given: `동식이` 행 케밥 메뉴가 열려 있음
- When: `삭제` 를 클릭한다
- Then: 메뉴가 닫히고 본문 `등록된 관찰 기록도 함께 삭제되며` / `삭제 후에는 복구할 수 없습니다` 인 확인 모달이 열린다

### S17: 개체 삭제 확인 → 성공 토스트
- Given: `동식이` 개체 삭제 확인 모달이 열려 있음
- When: `확인` 을 클릭한다
- Then: `동식이` 행이 사라지고 섹션 헤더가 `개체 2마리` 로 바뀌며 `데이터 삭제에 성공했습니다` 토스트가 뜬 뒤 사라진다

## 엣지 케이스

### S18: 개체 0마리 빈 상태
- Given: 개체가 0마리인 종 13(피라냐)
- When: `/species/13` 에 진입한다
- Then: 섹션 헤더 `개체 0마리`, 표 본문 `등록된 개체가 없습니다` / `오른쪽 위 [개체 등록하기]로 첫 개체를 추가해주세요` 가 보이고, 검색바는 보이며 페이지네이션은 없다

### S19: 검색 결과 없음
- Given: `/species/1` 화면
- When: 어떤 개체명에도 포함되지 않는 검색어를 입력한다
- Then: 행 대신 `검색결과가 없습니다` 가 보이고 페이지네이션이 보이지 않는다

### S20: 검색 시 1페이지로 리셋
- Given: `/species/2` 에서 2페이지를 보는 중
- When: 검색어를 입력한다
- Then: 결과가 1페이지부터 표시된다

### S21: 페이지네이션 경계 비활성
- Given: `/species/2` 1페이지
- When: 페이지네이션을 확인하고 마지막 페이지로 이동한다
- Then: 1페이지에서 `이전 페이지` 가, 마지막 페이지에서 `다음 페이지` 가 비활성이다

### S22: 케밥 메뉴는 하나만 열린다
- Given: `/species/1` 에서 `동식이` 행 케밥 메뉴가 열려 있음
- When: `미미` 행의 `⋮` 또는 카드 `⋮` 를 클릭한다
- Then: 이전 메뉴가 닫히고 새로 누른 메뉴만 열려 있다

### S23: 케밥 메뉴 닫기
- Given: 카드 또는 행 케밥 메뉴가 열려 있음
- When: 메뉴 바깥을 클릭하거나 `Escape` 를 누른다
- Then: 메뉴가 닫히고 `Escape` 의 경우 초점이 해당 `⋮` 로 돌아온다

### S24: 삭제 취소
- Given: 종 또는 개체 삭제 확인 모달이 열려 있음
- When: `취소` 를 클릭하거나 `Escape` 를 누른다
- Then: 모달이 닫히고 종 상세 화면과 행·`N마리` 가 그대로 남는다

### S25: 종 삭제 실패
- Given: 종 삭제가 실패하는 조건에서 종 삭제 확인 모달이 열려 있음
- When: `확인` 을 클릭한다
- Then: 모달이 닫히고 `/species/1` 에 머문 채 `데이터 삭제에 실패했습니다` 토스트가 뜬다

### S26: 개체 삭제 실패
- Given: 개체 삭제가 실패하는 조건(`toyvillage:individuals:fail` = `delete`)에서 개체 삭제 확인 모달이 열려 있음
- When: `확인` 을 클릭한다
- Then: 모달이 닫히고 `데이터 삭제에 실패했습니다` 토스트가 뜨며 행과 `개체 3마리` 가 그대로다

### S27: 마지막 개체 삭제 → 빈 상태
- Given: 개체가 1마리 남은 종의 상세
- When: 그 개체를 행 케밥으로 삭제하고 `확인` 을 누른다
- Then: 빈 상태 두 줄과 `개체 0마리` 로 바뀌고 페이지네이션이 없다

### S28: 개체 생성 성공 토스트
- Given: 개체 등록에 성공해 `/species/1` 로 돌아온 상태
- When: 종 상세 화면이 렌더된다
- Then: `데이터 생성에 성공했습니다` 토스트가 보이고 일정 시간 후 사라진다

### S29: 개체 상세 삭제 후 복귀 토스트
- Given: 개체 상세에서 개체를 삭제해 `/species/1` 로 돌아온 상태
- When: 종 상세 화면이 렌더된다
- Then: `데이터 삭제에 성공했습니다` 토스트가 보이고 삭제된 개체 행은 없다

### S30: 없는 종
- Given: 존재하지 않는 `speciesId`
- When: `/species/:speciesId` 로 진입한다
- Then: `종을 찾을 수 없습니다.` 와 `목록으로 돌아가기` 링크가 보이고, 링크를 누르면 `/species` 로 이동한다

### S31: 빈 값 표시
- Given: 법정지정분류와 세부분류가 없는 종 2
- When: `/species/2` 프로필 카드를 확인한다
- Then: `분류군` 값은 `조류` 이고, `법정지정분류` 와 `세부분류` 값 자리에 `—` 가 보인다

### S32: 키보드 조작
- Given: `/species/2` 화면
- When: 키보드만으로 카드·행 케밥 열기와 항목 실행, 행 진입, 검색 입력, 정렬 메뉴 선택, 페이지 이동을 시도한다
- Then: 모든 조작이 가능하고 포커스 표시가 outline 으로 보인다

### S33: 분류군·세부분류 표시
- Given: 세부 분류가 `설치목 - 천축서과` 인 종 1
- When: `/species/1` 프로필 카드를 확인한다
- Then: `분류군` 값이 `포유류 · 설치목 · 천축서과`, `세부분류` 값이 `천축서과` 로 보인다
