# 로딩 스켈레톤 · 목록 행동명세

## 목적

목록형 화면과 대시보드가 첫 조회 중일 때 빈 표나 "불러오는 중" 문구 대신 Figma `스켈레톤 · 목록`(`2021:24413`) 모양의 스켈레톤을 보인다. 이슈 #108의 1차 범위(공통 컴포넌트 + 목록)이고, 2026-09-20 Figma 재작업분(`2237:*`·`2238:*` 프레임)을 기준으로 한다.

## 동작 (source of truth)

- 화면의 첫 목록 조회가 끝나기 전에는 해당 화면의 스켈레톤을 보인다.
  - 스켈레톤 루트는 `role="status"`, `aria-busy="true"`, 접근 이름 `불러오는 중`을 가진다.
  - 스켈레톤 안의 막대는 스크린리더에 읽히지 않는다(`aria-hidden`).
- **서버 데이터가 아닌 UI는 조회 중에도 실제 UI 그대로 보인다.** 조회 결과로 채워지는 자리만 막대로 대체한다.
  - 실제로 보이는 것: 화면 제목·부제, 생성/등록 버튼, 사이드바 토글, 고정 탭 라벨(업무보고 심사 상태, 업무일지 목록/양식 등), 표 헤더 라벨, 검색바(플레이스홀더·아이콘 포함), 필터·조회날짜 선택기, 페이지 이동 화살표, 첨부 유형 아이콘, 카드 섹션 라벨.
  - 막대로 대체하는 것: 서버가 주는 값 — 표 행 셀, 카드 값, 팀 탭처럼 목록으로 받아오는 탭 이름, 페이지 번호, 달력 안의 휴관일 항목 등.
- 조회가 성공하면 막대가 사라지고 실제 값이 보인다.
- 조회가 실패하면 막대가 사라지고 기존 오류 표시를 그대로 보인다.
- 이미 데이터를 가진 상태의 재조회(검색·탭·페이지 이동으로 인한 placeholder 유지)에는 스켈레톤을 다시 보이지 않는다. 기존 동작 유지.

## 컴포넌트 구조/props

- `Skeleton` (shared/ui) — 막대 1개. `width`, `height`, `radius?`(기본 pill). Figma 채움: `#DBDBDB` 선형 그라데이션(알파 0.05 → 1, 0~50%).
- `SkeletonStatus` (shared/ui) — 스켈레톤 루트. `role="status"`, `aria-busy`, `aria-label="불러오는 중"`.
- 화면별 스켈레톤은 실제 화면 컴포넌트를 그대로 쓰고 값 자리에만 막대를 넣는다. 화면 전체를 복제한 별도 레이아웃을 두지 않는다. 표 형태는 공용 `TableSkeleton { columns, rows }`로 묶는다.
