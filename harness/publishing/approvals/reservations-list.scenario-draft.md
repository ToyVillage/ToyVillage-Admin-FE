# Scenario Draft — reservations-list

출처: `harness/publishing/specs/reservations-list.spec.md` (행동명세가 source of truth)
상태: draft (게이트 승인 전)

## 핵심 시나리오

### S1: 리스트 표시
- Given: `/notices/reservations` 진입
- Then: 타이틀 `단체예약 현황`, 상태 카드 3개(심사대기/승인 완료/반려, 각 카운트), `페이지 권한주기` 버튼, 테이블(헤더 상담일·예약일·예약 시간·단체명/지역·인원, 검색바, 행), 페이지네이션이 보인다

### S2: 상태 필터
- Given: 리스트 화면(기본 활성 `심사대기`)
- When: `반려` 카드를 클릭
- Then: 반려 상태 예약만 테이블에 보이고 `반려` 카드가 활성 표시된다

### S3: 검색
- Given: 리스트 화면
- When: 검색바에 단체명 일부를 입력
- Then: 단체명/지역이 일치하는 행만 남는다. 없으면 빈 상태 메시지를 표시한다

### S4: 정렬 (상담일순/예약일순)
- Given: 리스트 화면
- When: 필터 아이콘 클릭 → `예약일순` 선택
- Then: 예약일 기준으로 정렬되고 메뉴가 닫힌다

### S5: 행 클릭 → 상세 이동
- Given: 리스트 화면
- When: 첫 행을 클릭
- Then: `/notices/reservations/:id`로 이동한다

### S6: 선택 후 권한 모달 열기
- Given: 리스트 화면
- When: 한 행의 체크박스를 선택하고 `페이지 권한주기` 클릭
- Then: 권한 부여 모달이 열리고 직원 목록이 보인다

### S7: 선택 없이 권한 주기 → 안내
- Given: 아무 행도 선택하지 않음
- When: `페이지 권한주기` 클릭
- Then: 선택이 필요하다는 안내 모달을 표시하고, 확인 시 닫힌다

### S8: 권한 지정 확인/취소
- Given: 권한 부여 모달이 열림
- When: 직원을 선택하고 `확인`
- Then: 모달이 닫히고 행 선택이 초기화된다
- And: 취소 또는 Escape → 변경 없이 모달이 닫힌다

## 엣지 케이스

### S9: 데이터 없음 빈 상태
- Given: 예약 데이터가 하나도 없음
- Then: 테이블 대신 빈 상태 안내를 표시한다(검색 결과 없음과 구분)

### S10: 페이지네이션·리셋
- Given: 여러 페이지 분량의 예약
- When: 2페이지로 이동 후 상태 카드나 검색을 변경
- Then: 목록이 1페이지로 리셋된다
