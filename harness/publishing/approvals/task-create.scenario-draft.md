# Scenario Draft — task-create

출처: `harness/publishing/specs/task-create.spec.md` (행동명세가 source of truth)
기준 Figma: `yot`(`P7Jhnu8qV5m9q2QJNzkwAN`) `1:3694`
상태: draft (게이트 ② 승인 전)

## 핵심 시나리오

### S1: 빈 폼 진입
- Given: 목록 화면
- When: `업무 등록하기` 를 클릭한다
- Then: `/tasks/create` 로 이동하고 모든 필드가 비어 있다. 공개범위 필드는 존재하지 않는다

### S2: 우선순위 단일 선택
- Given: `/tasks/create` 화면
- When: 우선순위 `중` 을 클릭한다
- Then: `중` 만 선택 상태가 되고 `상`·`하` 는 해제 상태다

### S3: 완료기한 선택
- Given: `/tasks/create` 화면
- When: 완료기한 필드를 열어 날짜를 고르고 확인한다
- Then: 선택한 날짜가 필드에 표시된다

### S4: 팀 펼침·접힘
- Given: 담당자 트리의 모든 팀이 접혀 있음
- When: 팀 행의 chevron 을 클릭한다
- Then: 그 팀이 펼쳐져 소속 직원 행이 보이고, 다시 클릭하면 접힌다

### S5: 팀 전체 선택
- Given: 담당자 트리
- When: 팀 체크박스를 클릭한다
- Then: 그 팀 전원이 선택되고 카운트가 `5/5명` 처럼 전체 인원과 같아진다

### S6: 팀 부분 선택
- Given: 팀 전원이 선택된 상태
- When: 소속 직원 하나의 체크박스를 해제한다
- Then: 팀 체크박스가 부분 선택(`mixed`)이 되고 카운트가 하나 줄어든다

### S10: 필수값 입력 후 생성
- Given: `/tasks/create` 화면
- When: 우선순위·완료기한·담당자·제목·상세 내용을 채우고 `생성하기` 를 클릭한다
- Then: `/tasks` 로 이동하고 목록에 새 업무가 보인다

### S16: 첨부 추가·제거
- Given: `/tasks/create` 화면
- When: 파일을 업로드하고 다시 제거한다
- Then: chip 이 나타나며 성공 토스트가 뜨고, 제거하면 chip 이 사라진다

### S19: 담당자 다중 선택 결과
- Given: 담당자를 2명 이상 고른 상태
- When: 업무를 생성하고 목록으로 돌아온다
- Then: 그 업무의 담당자 셀이 `이름 외 N명` 으로 보인다

## 엣지 케이스

### S7: 전체 직원 토글
- Given: 담당자 트리, 아무도 선택되지 않음
- When: `전체 직원` 체크박스를 클릭한다
- Then: 모든 팀·직원이 선택되고 카운트가 `18/18명` 이 된다. 다시 클릭하면 전부 해제된다

### S8: 전체 직원 부분 선택 표시
- Given: 일부 직원만 선택된 상태
- When: `전체 직원` 행을 확인한다
- Then: 체크박스가 부분 선택(`mixed`)으로 보인다

### S9: 접어도 선택 유지
- Given: 팀을 펼쳐 직원 일부를 선택한 상태
- When: 그 팀을 다시 접는다
- Then: 카운트가 그대로 유지되고 다시 펼치면 선택이 남아 있다

### S11: 우선순위 미선택 검증
- Given: 우선순위만 비운 상태
- When: `생성하기` 를 클릭한다
- Then: 요청을 보내지 않고 `우선순위를 선택해주세요` 모달이 뜬다

### S12: 완료기한 미선택 검증
- Given: 완료기한만 비운 상태
- When: `생성하기` 를 클릭한다
- Then: `완료기한을 선택해주세요` 모달이 뜬다

### S13: 담당자 미선택 검증
- Given: 담당자를 아무도 고르지 않은 상태
- When: `생성하기` 를 클릭한다
- Then: `담당자를 선택해주세요` 모달이 뜬다

### S14: 제목 미입력 검증
- Given: 제목만 비운 상태
- When: `생성하기` 를 클릭하고 모달의 `확인` 을 누른다
- Then: `제목을 입력해주세요` 모달이 뜨고 확인 후 제목 입력으로 포커스가 이동한다

### S15: 상세 내용 미입력 검증
- Given: 상세 업무 내용만 비운 상태
- When: `생성하기` 를 클릭한다
- Then: `상세 업무 내용을 입력해주세요` 모달이 뜬다

### S17: 이탈 보호
- Given: 입력이 하나라도 있는 상태
- When: `뒤로가기` 를 클릭한다
- Then: `정말 나가시겠습니까?` 모달이 뜨고 `취소` 를 누르면 입력이 유지된다

### S18: 생성 중복 제출 방지
- Given: 생성 요청이 진행 중
- When: `생성하기` 를 다시 클릭한다
- Then: 요청이 한 번만 전송된다

### S20: 키보드 조작
- Given: `/tasks/create` 화면
- When: 키보드만으로 입력·트리 조작·검증·생성을 시도한다
- Then: 모든 조작이 가능하고 포커스 표시가 outline 으로 보인다
