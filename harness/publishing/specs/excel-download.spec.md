## 항목 선택

- 항목 카드 아무 곳이나 클릭 → 그 항목의 선택이 바뀐다.
- `선택한 항목` 개수는 선택이 바뀔 때마다 갱신한다.
- `전체 선택` 체크박스 상태
  - 10개 모두 선택: 선택
  - 1–9개 선택: 일부 선택(가로줄)
  - 0개 선택: 해제
- `전체 선택` 클릭
  - 0개 선택된 상태 → 10개 모두 선택
  - 일부(1–9개) 또는 10개 모두 선택된 상태 → 모두 해제
  - 업무지시 담당자 선택(`TaskAssigneeTree`)과 같은 방식이다(2026-10-27 사용자 결정).
- `동물 리스트`·`직원 계정 관리`는 기간과 관계없이 내보낸다(`기간 미적용`). 이 항목만 선택해도 기간 입력은 그대로 둔다.

## 기간 선택

- 기간 버튼은 하나만 선택된다.
- 기간 버튼 클릭 → 날짜 입력과 요약의 기간을 바로 바꾼다.

| 버튼        | 시작일                   | 종료일   |
| ----------- | ------------------------ | -------- |
| `전체 기간` | 비움                     | 비움     |
| `오늘`      | 오늘                     | 오늘     |
| `최근 1주`  | 오늘의 7일 전            | 오늘     |
| `최근 1개월`| 오늘의 한 달 전 같은 날  | 오늘     |
| `최근 3개월`| 오늘의 석 달 전 같은 날  | 오늘     |
| `직접 선택` | 현재 시작일 유지         | 비움     |

- 같은 날이 없는 달은 그 달의 마지막 날로 맞춘다. 예: 5월 31일의 석 달 전은 2월 28일(윤년이면 29일).
- `전체 기간`이면 날짜 입력 두 개를 비활성화하고 `연도. 월. 일`로 표시한다. 요약의 기간은 `전체 기간`으로 표시한다(2026-10-27 사용자 결정).
- `직접 선택` 클릭 → 시작일 달력을 연다(Figma `2995:25375`, 2026-10-27 사용자 결정). `전체 기간`에서 넘어와 시작일이 비어 있으면 시작일도 비운다.
- 다른 기간 버튼이 선택된 상태에서 날짜 입력을 눌러 날짜를 바꾸면 기간 버튼은 `직접 선택`으로 바뀐다.

### 날짜 입력과 달력

- 날짜는 `YYYY. MM. DD` 형식으로 표시한다.
- 날짜 입력 클릭 → 그 입력 아래에 달력을 연다. 달력은 입력의 현재 날짜가 있는 달을 보여 주고, 비어 있으면 이번 달을 보여 준다.
- 달력에서 날짜 클릭 → 그 입력에 값을 넣고 달력을 닫는다.
- 좌우 화살표 → 이전·다음 달로 넘긴다.
- 달력 밖 클릭 또는 Esc → 값을 바꾸지 않고 달력을 닫는다. Esc로 닫으면 포커스는 그 날짜 입력으로 돌아간다.
- 종료일 달력에서는 시작일보다 앞선 날짜를 고를 수 없다(비활성 표시).
- 시작일을 현재 종료일보다 뒤로 바꾸면 종료일을 비운다.
- 미래 날짜 선택 제한은 Figma에 없으므로 두지 않는다.
- Figma 달력의 17일 아래 빨간 점은 컴포넌트 예시 표시로 보고 이 화면에서는 그리지 않는다.

## 다운로드 요약과 버튼

- `선택한 항목`: `N개`
- `기간`
  - 시작일·종료일 모두 있음: `YYYY. MM. DD ~ YYYY. MM. DD`
  - 종료일만 비어 있음: `YYYY. MM. DD ~`
  - `전체 기간`: `전체 기간`
- `파일 형식`: 고른 형식의 확장자(`.xlsx`, `.zip`)
- `엑셀 다운로드` 버튼 비활성 조건과 사유 문구(위에서부터 먼저 맞는 하나만 표시)
  1. 선택한 항목 0개 → `항목을 1개 이상 선택해주세요`
  2. `전체 기간`이 아니고 시작일이 비어 있음 → `시작일을 선택해주세요`
  3. `전체 기간`이 아니고 종료일이 비어 있음 → `종료일을 선택해주세요`
- 위 조건에 해당하지 않으면 버튼을 활성화하고 사유 문구를 표시하지 않는다.
- 활성 버튼 클릭 → 선택한 항목·기간·파일 형식으로 다운로드 요청을 한 번 보낸다. 버튼 라벨은 파일 형식과 관계없이 그대로다.
- 요청 중에는 버튼을 비활성화해 중복 요청을 막는다. 라벨은 그대로 둔다.
- 결과 토스트는 Figma `엑셀 다운로드 · 토스트`를 따른다. 위치 top 32px·right 48px, padding 20px 24px, radius 12px, 아이콘 40px, 아이콘과 글자 간격 12px, 글자 28px이고 폭은 440px에서 시작해 문구에 맞춰 늘어난다. 조건과 문구는 API 연동 spec(`harness/api/specs/excel-export.spec.md`)이 정한다.

```ts
  /** `YYYY-MM-DD`. `전체 기간`이면 null. */
  startDate: string | null
  /** `YYYY-MM-DD`. `전체 기간`이면 null. */
  endDate: string | null
  /** 파일 형식 */
  mode: 'SHEET' | 'ZIP'
}
```

- 실제 요청은 `entities/excel-export`의 API 함수로 보낸다. 엔드포인트, 항목과 서버 값 대응, 파일 이름은 `harness/api/specs/excel-export.spec.md`를 따른다.
- 서버 요청은 TanStack Query mutation으로 감싼다. 항목·기간 선택은 feature 로컬 상태로 둔다.

## 컴포넌트 구조와 소유권

- `ExcelDownloadPage` (`pages/settings/excel-download`) — 제목과 세 카드 배치
- `ExcelExportForm` (`features/export-excel`) — 항목·기간 상태, 비활성 조건, 다운로드 mutation
- `ExportTargetGrid` (`features/export-excel`) — `전체 선택`과 항목 카드 10개
- `ExportFormatField` (`features/export-excel`) — 파일 형식 선택
- `ExportPeriodField` (`features/export-excel`) — 기간 버튼과 시작일·종료일 입력
- `ExportSummary` (`features/export-excel`) — 개수·기간·파일 형식·다운로드 버튼·사유 문구
- `ExcelExportTarget`, `ExcelExportRequest`, API 함수 (`entities/excel-export`)
- 재사용 후보(컴포넌트맵에서 확정): `PageHeader`, `PillButton`/`PillRadioGroup`
- 달력은 Figma 모양을 따른다. 단체예약 폼의 `features/reservation-form/ui/DateCalendar`를 `shared/ui`로 옮겨 함께 쓴다(2026-10-27 사용자 결정). 브라우저 기본 달력(`DateField`)은 쓰지 않는다.
- 새 date-picker·checkbox 라이브러리를 추가하지 않는다.

## 접근성

- 화면 제목은 `h1`이다.
- 항목은 native checkbox이며 접근 가능한 이름은 항목 이름(예: `관찰일지`), 설명은 기준 문구로 연결한다.
- `전체 선택`은 native checkbox이며 일부 선택일 때 `indeterminate`로 `mixed` 상태를 전달한다.
- 기간 버튼은 이름이 `기간`인 radio group이다. 화살표 키로 선택을 옮길 수 있다.
- 파일 형식은 이름이 `파일 형식`인 radio group이다. 각 라디오의 접근 가능한 이름은 선택지 이름, 설명은 설명 문구로 연결한다.
- 날짜 입력은 `시작일`, `종료일` 이름을 가진 버튼이며 달력 열림 여부를 `aria-expanded`로 전달한다.
- 달력은 이름이 `시작일 선택`·`종료일 선택`인 dialog이고, 날짜 버튼의 이름은 `YYYY년 M월 D일` 형식이다.
- 비활성 사유 문구는 버튼에 `aria-describedby`로 연결하고 status 영역으로 알린다.
- 포커스 상태는 색만이 아닌 명확한 outline으로 표시한다.
- 키보드 순서: `전체 선택` → 항목 10개 → 파일 형식 → 기간 버튼 → 시작일 → 종료일 → `엑셀 다운로드`

## 반응형

- Figma에는 1920×1080 데스크톱만 있다.
- 1384px 이하에서는 항목 격자를 2열로(본문이 1320px보다 좁아지면 5열에서 긴 이름이 줄바꿈된다), 980px 이하에서는 1열로 바꾼다.
- 980px 이하에서는 파일 형식 선택지를 세로로 쌓는다.
- 980px 이하에서는 `기간` 카드와 다운로드 요약 카드를 세로로 쌓는다.
- 기간 버튼은 줄바꿈되며 가로 스크롤을 만들지 않는다.
- 모바일 정밀 배치는 Figma 미제공 항목이다.

## 기능 테스트 수용 기준

- S1: 사이드바 `설정` > `엑셀 다운로드` 클릭 → `/settings/excel-download`로 이동하고 `엑셀 다운로드` 제목이 보인다.
- S2: 첫 진입 → 항목 10개와 `전체 선택`이 모두 해제되고, `최근 1개월`과 `엑셀 파일 (.xlsx)`이 선택되고, 요약 파일 형식이 `.xlsx`이고, 시작일·종료일이 오늘의 한 달 전~오늘이며, `선택한 항목` `0개`, 버튼 비활성과 `항목을 1개 이상 선택해주세요`가 보인다.
- S3: 항목 카드 클릭 → 그 항목이 선택되고 `선택한 항목` 개수가 늘며 `전체 선택`이 일부 선택 상태가 된다. 다시 클릭하면 해제된다.
- S4: `전체 선택` 클릭 → 10개 모두 선택되고 `10개`가 보인다. 다시 클릭하면 모두 해제되고 `0개`가 보인다.
- S5: 일부 선택 상태에서 `전체 선택` 클릭 → 모두 해제되고 `0개`, 버튼 비활성과 `항목을 1개 이상 선택해주세요`가 보인다.
- S6: 항목 10개를 하나씩 모두 선택 → `전체 선택`이 선택 상태가 된다.
- S7: `오늘`·`최근 1주`·`최근 3개월` 클릭 → 날짜 입력과 요약의 기간이 표대로 바뀐다.
- S8: `전체 기간` 클릭 → 날짜 입력이 비활성화되고 요약 기간이 `전체 기간`이며, 항목을 고르면 버튼이 활성화된다.
- S9: 항목을 고른 뒤 `직접 선택` 클릭 → 종료일이 비고 시작일 달력이 열리며, 버튼 비활성과 `종료일을 선택해주세요`, 요약 기간 `YYYY. MM. DD ~`가 보인다.
- S10: 달력에서 종료일 선택 → 달력이 닫히고 버튼이 활성화되며 요약 기간이 갱신된다.
- S11: `최근 1개월` 상태에서 시작일을 달력으로 바꾸면 기간 버튼이 `직접 선택`으로 바뀐다.
- S12: 종료일 달력에서 시작일보다 앞선 날짜는 고를 수 없다.
- S13: 시작일을 종료일보다 뒤로 바꾸면 종료일이 비고 `종료일을 선택해주세요`가 보인다.
- S14: 달력에서 Esc → 값이 바뀌지 않고 달력이 닫히며 포커스가 날짜 입력으로 돌아간다.
- S15: 활성 버튼을 빠르게 두 번 클릭해도 오류 없이 화면 상태가 유지된다. 요청 횟수·내용은 API 테스트(`tests/e2e/api/excel-export.spec.ts`)가 검증한다.
- S16: 키보드만으로 항목 선택, 기간 선택, 날짜 선택, 파일 형식 선택, 다운로드 버튼까지 조작할 수 있다.
- S17: 첫 진입에 `엑셀 파일 (.xlsx)`이 선택되어 있고, `압축 파일 (.zip)` 카드를 누르면 그쪽으로 바뀌고 요약이 `.zip`이 되며 버튼 라벨은 그대로다.
