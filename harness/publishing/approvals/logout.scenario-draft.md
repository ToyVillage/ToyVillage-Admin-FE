# Scenario Draft — logout

출처: `harness/publishing/specs/logout.spec.md` (행동명세가 source of truth)
상태: draft (게이트 승인 전)

## 핵심 시나리오

### S1: 사이드바 하단에 로그아웃 항목이 보인다
- Given: 로그인 세션이 저장된 상태로 `/` 에 진입했다
- When: 메뉴 아이콘(`사이드바 열기`)을 눌러 사이드바를 연다
- Then: 사이드바 안에 이름이 `로그아웃` 인 버튼이 보이고, 활성(선택) 표시가 없다

### S2: 로그아웃하면 세션이 지워지고 로그인 화면으로 이동한다
- Given: 로그인 세션(`accessToken` · `refreshToken` · 사용자 정보)이 저장된 상태로 사이드바를 열었다
- When: `로그아웃` 버튼을 누른다
- Then: 확인 절차 없이 `/login` 으로 이동하고, 저장된 토큰 2개와 사용자 정보가 모두 지워진다

## 엣지 케이스

### S3: 로그아웃 후 뒤로 가기로 이전 화면에 돌아가지 않는다
- Given: `/tasks` 에서 사이드바를 열고 `로그아웃` 을 눌러 `/login` 에 도착했다
- When: 브라우저 뒤로 가기를 한다
- Then: 로그인이 필요한 화면(`/tasks`)이 표시되지 않는다

### S4: 로그아웃 후 인증이 필요한 경로에 직접 들어가면 로그인 화면으로 간다
- Given: 로그아웃을 마쳤다
- When: 주소창으로 `/` 에 직접 진입한다
- Then: `/login` 으로 이동한다

### S5: 화면 높이가 낮아도 로그아웃 항목이 패널 안에 남는다
- Given: 뷰포트 높이가 낮은(예: 1280×600) 상태로 사이드바를 열고 대분류를 펼쳐 메뉴가 길어졌다
- When: 로그아웃 항목의 위치를 확인한다
- Then: `로그아웃` 버튼이 뷰포트 안에 보이고 클릭할 수 있다
