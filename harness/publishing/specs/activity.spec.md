## 범위

- 포함: 유형 탭, 날짜 이동(이전·다음·달력·오늘), 먹이 급여 4층/5층 전환과 표, 관찰일지 표, 업무일지 표,
  빈 상태, 사이드바 항목 라우트 연결
- 제외: 실제 API 연동(`/api` 스킬 담당 — 전체 활동 API 는 아직 없다), 행 클릭 이동, 페이지네이션,
  모바일(360) 레이아웃(Figma 없음)

## 라우트와 진입

- `/activity` → 전체 활동을 표시한다. 기본 탭은 `먹이 급여`, 기본 날짜는 오늘, 기본 층은 `4층`이다.
- 탭·날짜·층은 쿼리스트링으로 유지한다: `?tab=feed|observation|work-log`, `?date=YYYY-MM-DD`, `?floor=4|5`.
  값이 없거나 알 수 없으면 기본값으로 간주한다. 새로고침과 뒤로가기에서 그대로 복원된다.
- 사이드바 `업무관리` 그룹의 `업무일지관리` 아래에 `전체 활동` 항목을 두고 `/activity` 로 연결한다

## 동작 (behavioral spec — source of truth)

### 공통

- 화면 진입 → 제목 `전체 활동`, 부제 `직원이 올린 기록을 날짜별로 한눈에 확인해요`, 왼쪽에 유형 탭
  (`먹이 급여` / `관찰일지` / `업무일지`), 오른쪽에 날짜 선택(이전 · 날짜 · 다음 · 오늘)이 보인다.
- 유형 탭 클릭 → 그 유형의 표로 바뀌고 URL 의 `tab` 이 갱신된다. 선택한 날짜는 유지된다.
  선택된 탭은 진한 배경(`#36363F`)에 흰 글자, 나머지는 흰 배경·테두리(`#DDDDE3`)에 회색 글자다.
- 날짜 칸에는 `YYYY. MM. DD (요일)` 형식으로 선택한 날짜를 보여준다. 예: `2026. 10. 20 (화)`.
- `이전 날짜` 클릭 → 하루 전으로, `다음 날짜` 클릭 → 하루 뒤로 바뀌고 표가 그 날짜 기록으로 바뀐다.
- `오늘` 클릭 → 오늘 날짜로 바뀐다. 선택한 날짜가 오늘이면 `오늘` 버튼이 활성 모양(파란 테두리·배경·글자)이고,
  아니면 다른 버튼과 같은 흰 모양이다.
- 날짜 칸 클릭 → 날짜 칸 테두리가 파란색(2px)이 되고 그 아래에 달력이 열린다. 달력은 선택한 날짜가 있는 달을 보여준다.
  - 달력 머리의 `<` / `>` 클릭 → 이전 달 / 다음 달로 넘어간다.
  - 날짜 클릭 → 그 날짜가 선택되고 달력이 닫히며 표가 그 날짜 기록으로 바뀐다.
  - 선택한 날짜는 파란 원(`#4952FF`)에 흰 글자, 앞뒤 달의 날짜는 흐린 글자(`#AFAFBA`)다.
  - 달력 바깥 클릭이나 `Escape` → 달력이 닫히고 날짜는 바뀌지 않는다.
- 날짜를 바꾸면 URL 의 `date` 가 갱신된다.
- 표의 행을 클릭해도 아무 일도 일어나지 않는다.
- 하루치 기록을 한 표에 모두 보여준다(페이지네이션 없음).

### 먹이 급여 탭 (`?tab=feed`)

- 유형 탭 아래에 층 선택(`4층` / `5층`)이 있다. 디자인 시스템 `title/tabbar`(`CategoryTabs`)를 쓰고, 선택된 층은 밑줄로 표시한다.
- 층 클릭 → 그 층의 표로 바뀌고 URL 의 `floor` 가 갱신된다.
- 표는 층 탭 바로 아래에 있다. 층 이름·분류·건수 요약 머리는 두지 않는다(층은 탭에 있고, 건수는 표 행으로 보인다).
- 4층 표의 열: `일반명` / `개체명` / `급여시간` / `먹이 종류` / `급여량` / `잔량` / `특이사항` / `급여자`.
  - 급여량·잔량은 숫자 뒤에 앱이 고른 단위를 붙인다. 예: `200 g/ml`.
  - 특이사항이 없으면 `-` 를 보여준다. 칸보다 길면 한 줄로 자르고 말줄임표를 붙인다.
  - 행은 급여시간 오름차순이다.
- 5층 표의 열: `일반명` / `개체명` / `먹이 종류` / `급여량` / `급여자`. 행은 등록 순서다.
- 그 층에 그 날짜 기록이 없으면 → 표 머리 행은 두고 행 자리에
  `이 날짜에 올라온 먹이 급여 기록이 없어요` / `다른 날짜를 선택해 보세요` 를 보여준다(Figma `3379:25998`).

### 관찰일지 탭 (`?tab=observation`)

- 업무일지 탭과 같은 모양의 표다(Figma `3039:25821`). 층 선택은 없다.
- 표의 열: `작성시간` / `일반명` / `개체명` / `제목` / `관찰자` / `첨부`. 첨부는 `<개수>개`, 없으면 `-`.
  행은 작성시간 오름차순이다.
- 기록이 없으면 → `이 날짜에 올라온 관찰일지가 없어요` / `다른 날짜를 선택해 보세요` (Figma `3379:26434`).

### 업무일지 탭 (`?tab=work-log`)

- 표의 열: `작성시간` / `양식` / `제목` / `작성자` / `첨부`. 첨부는 `<개수>개`, 없으면 `-`. 행은 작성시간 오름차순이다.
  열 폭: 작성시간 160 / 양식 280 / 제목 나머지 / 작성자 220 / 첨부 160. 제목이 길면 말줄임(2026-10-29 개발자 요청 — 제목 열 추가, 업무일지 API에 제목 필드 없음 → 백엔드 요청).
- 기록이 없으면 → `이 날짜에 올라온 업무일지가 없어요` / `다른 날짜를 선택해 보세요` (Figma `3039:26991`).

## 데이터

- 퍼블리싱 단계에서는 날짜별 mock 데이터로 둔다(전체 활동 API 미정, `/api` 스킬이 연동).
  - 쿼리키 후보: `['activity', 'feed', { date, floor }]`, `['activity', 'observation', { date }]`,
    `['activity', 'work-log', { date }]`
- 클라이언트 상태: 탭·날짜·층은 URL, 달력 열림·보이는 달은 컴포넌트 지역 상태. Zustand 는 쓰지 않는다.

## 컴포넌트 구조/props

- `ActivityPage` — `/activity` 화면. URL 의 탭·날짜·층을 읽고 쓴다.
- `ActivityTypeTabs { value, onChange }` — 유형 탭(pill 3개).
- `DayNavigator { value, onChange }` (shared/ui) — 이전·날짜 칸·다음·오늘 + 달력 팝오버.
- `MonthCalendar { value, onSelect }` (shared/ui) — 달력 팝오버 본문(Figma `3071:27258`, 392×506).
- 층 선택은 `CategoryTabs` (shared/ui, 디자인 시스템 `title/tabbar`)를 그대로 쓴다.
- 표는 `DataTable` (shared/ui, 디자인 시스템 `list`) 기본 외형을 쓴다. 세 유형이 열 정의만 바꿔 같은 표를 쓴다.
