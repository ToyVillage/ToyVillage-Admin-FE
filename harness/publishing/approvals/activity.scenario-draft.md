# Scenario Draft — activity

출처: `harness/publishing/specs/activity.spec.md` (행동명세가 source of truth)
상태: draft (게이트 승인 전)

> 데이터는 퍼블리싱 mock 이다. 테스트는 날짜를 고정(2026-10-20)한 URL 로 들어가 mock 기록을 확인한다.

## 핵심 시나리오

### S1: 기본 진입은 먹이 급여 · 오늘 · 4층이다
- Given: `/activity` 에 쿼리 없이 들어간다.
- When: 화면이 열린다.
- Then: 제목 `전체 활동`, 부제 `직원이 올린 기록을 날짜별로 한눈에 확인해요` 가 보이고, `먹이 급여` 탭과 `4층` 이
  선택돼 있으며, 날짜 칸에 오늘 날짜가 `YYYY. MM. DD (요일)` 로 보이고 `오늘` 버튼이 활성 모양이다.

### S2: 4층 표는 앱 입력 칸만 보여준다
- Given: `/activity?tab=feed&date=2026-10-20&floor=4` 이다.
- When: 화면이 열린다.
- Then: 층 탭 바로 아래에 표가 있고(층 이름·건수 요약 머리는 없다), 표 머리 열이 `일반명` `개체명` `급여시간` `먹이 종류`
  `급여량` `잔량` `특이사항` `급여자` 순서다. `먹이반응`·`상태`·`사료`·`채소류`·`단백질` 열과 상태 범례는 없다.
  급여량·잔량은 `200 g/ml` 처럼 단위가 붙고, 행은 급여시간 오름차순이다.

### S3: 5층으로 바꾸면 5층 표와 URL 이 바뀐다
- Given: S2 상태다.
- When: `5층` 을 누른다.
- Then: URL 에 `floor=5` 가 남고, 5층 기록 24행이 보이고, 표 머리 열이 `일반명` `개체명` `먹이 종류`
  `급여량` `급여자` 순서로 보인다.

### S4: 이전·다음 날짜로 하루씩 이동한다
- Given: `/activity?date=2026-10-20` 이다.
- When: `이전 날짜` 를 누른다. 다시 `다음 날짜` 를 두 번 누른다.
- Then: 날짜 칸이 `2026. 10. 19 (월)` → `2026. 10. 21 (수)` 로 바뀌고 URL 의 `date` 도 같이 바뀐다.
  오늘이 아니므로 `오늘` 버튼은 흰 모양이다.

### S5: 오늘 버튼은 오늘 날짜로 돌아온다
- Given: `/activity?date=2026-10-20` 이고 오늘이 아니다.
- When: `오늘` 을 누른다.
- Then: 날짜 칸이 오늘 날짜가 되고 `오늘` 버튼이 활성 모양이 된다.

### S6: 달력에서 날짜를 고른다
- Given: `/activity?date=2026-10-20` 이다.
- When: 날짜 칸을 누르고, 열린 달력에서 `>` 를 눌러 다음 달로 넘긴 뒤 `3` 을 누른다.
- Then: 달력이 열릴 때 머리가 `2026년 10월` 이고 20일이 선택 모양이다. 다음 달로 넘기면 `2026년 11월` 이 되고,
  `3` 을 누르면 달력이 닫히며 날짜 칸이 `2026. 11. 03 (화)` 가 된다.

### S7: 유형 탭을 바꿔도 날짜는 유지된다
- Given: `/activity?date=2026-10-20` 이다.
- When: `업무일지` 탭을 누른다.
- Then: URL 에 `tab=work-log` 와 `date=2026-10-20` 이 남고, 표 머리 열이 `작성시간` `양식` `제목` `작성자` `첨부` 이며
  `개장 전 점검일지` 행의 제목은 `정문·매표소 개장 전 점검` 이다. 첨부가 없는 행은 `-`, 있는 행은 `<개수>개` 다.

### S8: 관찰일지 탭은 앱 관찰 기록 칸을 보여준다
- Given: `/activity?tab=observation&date=2026-10-20` 이다.
- When: 화면이 열린다.
- Then: 층 선택 없이 표 머리 열이 `작성시간` `일반명` `개체명` `제목` `관찰자` `첨부` 순서로 보이고,
  첨부가 없는 행은 `-`, 있는 행은 `<개수>개` 이며 행은 작성시간 오름차순이다.

## 엣지 케이스

### S9: 기록이 없는 날은 빈 상태를 보여준다
- Given: mock 기록이 없는 날짜 `2026-10-22` 다.
- When: 업무일지 탭으로 들어간다.
- Then: 표 머리 행 아래에 `이 날짜에 올라온 업무일지가 없어요` 와 `다른 날짜를 선택해 보세요` 가 보인다.
  먹이 급여 탭과 관찰일지 탭도 같은 날 각자의 빈 상태 문구를 보여준다.

### S10: 달력은 바깥 클릭이나 Escape 로 닫히고 날짜는 그대로다
- Given: 날짜 칸을 눌러 달력이 열렸다.
- When: `Escape` 를 누른다. 다시 열고 달력 바깥을 누른다.
- Then: 두 경우 모두 달력이 닫히고 날짜 칸은 바뀌지 않는다.

### S11: 행을 눌러도 이동하지 않는다
- Given: 먹이 급여 4층 표에 행이 있다.
- When: 첫 행을 누른다.
- Then: URL 이 바뀌지 않는다.

### S12: 잘못된 쿼리는 기본값으로 본다
- Given: `/activity?tab=unknown&floor=7&date=not-a-date` 로 들어간다.
- When: 화면이 열린다.
- Then: `먹이 급여` 탭, `4층`, 오늘 날짜로 보인다.

### S13: 새로고침해도 탭·날짜·층이 유지된다
- Given: `/activity?tab=feed&date=2026-10-20&floor=5` 다.
- When: 새로고침한다.
- Then: `5층` 표와 `2026. 10. 20 (화)` 가 그대로 보인다.
