## 목적

운영 관리자가 토이빌리지의 부서별 팀을 만들고, 팀 이름을 고치고, 팀을 지우고,
각 팀에 직원을 넣고 빼는 화면이다. 좌측 팀 목록(rail)에서 팀을 고르면 우측 패널에 그 팀의 상세가 뜬다.

## 범위

- 포함: 팀 목록 rail, 팀 선택, 팀 추가 모달, 팀명 인라인 수정, 팀 삭제(확인 모달 + 토스트),
  팀원 표, 팀원 추가 모달(검색·선택·확정), 팀원 제거, 빈 상태, 사이드바 `팀 설정` 항목 라우트 연결
- 제외: 실제 API 연동(`/api` 스킬 담당), 직원 계정 관리·권한 관리, 팀원 정렬·페이지네이션,
  Figma 에 없는 로딩·에러·404 화면

## 라우트와 진입

- `/settings/teams` → 팀 관리 화면을 표시한다.
- 사이드바 `설정 > 팀 설정` 항목의 이동 대상을 `/settings/teams` 로 지정한다.
  사이드바 자체의 동작 계약은 `harness/publishing/specs/sidebar.spec.md` 를 따르며 이 spec 은 `to` 지정만 한다.

## 동작 (behavioral spec — source of truth)

### 진입과 팀 선택

- 화면 진입 → 제목 `팀 관리`, 부제 `토이빌리지 부서별 팀 인원 설정` 이 보이고,
  좌측 rail 과 우측 상세 패널이 나란히 놓인다.
- rail 헤더는 `팀` 과 `N개` 다. `N` 은 팀 개수다.
- rail 의 각 행은 `팀 이름` 과 `N명`(그 팀의 팀원 수)이다.
- 진입 시 **첫 번째 팀이 선택**된 상태다. 선택된 행은 검은 배경 + 흰 글자이고, 나머지는 흰 배경 + 검은 글자다.
- rail 행 클릭 → 그 팀이 선택되고 우측 패널이 그 팀의 상세로 바뀐다.
  팀명 수정 모드였다면 해제되고 편집 중이던 이름은 버린다.
- 팀이 하나도 없으면 rail 은 헤더(`팀` `0개`)와 `＋  팀 추가하기` 만 남고,
  우측 패널은 렌더하지 않는다. (Figma 에 "팀 0개" 프레임이 없어 패널을 비우는 쪽으로 정한다 — 중간 게이트 확인 대상)

### 팀 상세 패널

- 패널 상단에 팀 이름(40px), 오른쪽에 `팀명 변경` / `팀 삭제` 버튼이 있다.
- 구분선 아래에 `팀원` + `N명` 과 `＋  인원 추가하기` 버튼이 있다.
- 팀원 표의 열은 `이름` / `직급` 이고, 각 행 오른쪽에 `제거` 버튼이 있다.
  직급이 없는 직원은 `사원` 으로 표시한다.
- 팀원이 0명이면 표 대신 빈 상태를 표시한다 —
  제목 `아직 팀원이 없어요`, 설명 `인원 추가하기를 눌러 이 팀에서 일할 직원을 넣어 주세요`.
  표 머리행도 함께 숨긴다.
- `제거` 클릭 → 확인 없이 그 팀원이 표에서 빠지고, `팀원 N명` 과 rail 행의 `N명` 이 함께 줄어든다.
  마지막 팀원을 제거하면 빈 상태로 바뀐다.

### 팀 추가

- rail 하단 `＋  팀 추가하기` 클릭 → `팀 추가하기` 모달이 열린다.
  `팀 이름` 라벨 + 입력(placeholder `팀 이름`) + `취소` / `완료` 버튼.
- 입력이 비어 있거나 공백뿐이면 `완료` 는 비활성이다.
- `완료` 클릭 → 그 이름의 팀이 팀원 0명으로 생성되고, 모달이 닫히며,
  rail 맨 아래에 새 팀이 추가되고 **그 팀이 선택**되어 우측 패널이 빈 상태를 보여준다.
- `취소` 클릭 / 딤 바깥 클릭 / `Escape` → 팀을 만들지 않고 모달이 닫힌다.

### 팀명 변경

- `팀명 변경` 클릭 → 제목 자리가 팀 이름 입력(현재 이름이 채워진 상태)으로 바뀌고,
  오른쪽 버튼이 `저장` / `취소` 로 바뀐다. 입력에 포커스가 가고 커서는 텍스트 끝에 있다.
- 입력이 비어 있거나 공백뿐이면 `저장` 은 비활성이다.
- `저장` 클릭 또는 `Enter` → 팀 이름이 바뀌고 수정 모드가 풀린다.
  rail 의 해당 행 이름도 함께 바뀐다.
- `취소` 클릭 또는 `Escape` → 이름을 되돌리고 수정 모드가 풀린다.

### 팀 삭제

- `팀 삭제` 클릭 → 공통 삭제 확인 모달(`정말 삭제하시겠습니까?` / `삭제하신 뒤에는 영구삭제되며 복구 할 수 없습니다`)이 열린다.
- `취소` 또는 `Escape` → 아무것도 지우지 않고 모달이 닫힌다.
- `확인` → 모달이 닫히고 팀이 rail 에서 사라지며,
  성공 토스트 `데이터 삭제에 성공했습니다` 가 뜬다.
  실패하면 실패 토스트 `데이터 삭제에 실패했습니다` 가 뜨고 팀은 그대로 남는다.
- 삭제 후에는 rail 의 **첫 번째 팀**이 선택된다. 남은 팀이 없으면 우측 패널을 렌더하지 않는다.
- 토스트는 팀 삭제 결과에만 띄운다. 팀 생성·팀명 변경·팀원 추가/제거는 토스트 없이 화면만 갱신한다.

### 팀원 추가

- `＋  인원 추가하기` 클릭 → `팀원 추가` 모달이 열린다.
  제목 `팀원 추가`, 부제 `<팀 이름>에 추가할 직원을 골라 주세요`, `이름으로 검색` 입력,
  직원 목록, `취소` / `추가 완료` 버튼.
- 목록에는 **그 팀에 아직 속하지 않은 직원**만 나온다. 각 행은 아바타 / 이름 / 직급 / `추가` 버튼이다.
- 행의 `추가` 클릭 → 그 직원이 선택되고, 버튼이 `선택 취소`(흰 배경 + 회색 테두리)로 바뀌며,
  목록 맨 위 `추가할 인원 N명` 그룹으로 옮겨간다. 그 아래 구분선과 `전체 직원` 라벨이 생긴다.
- 선택된 행의 `선택 취소` 클릭 → 선택이 풀리고 `전체 직원` 그룹으로 되돌아간다.
  선택이 0명이 되면 `추가할 인원` 그룹과 `전체 직원` 라벨·구분선이 사라진다.
- 검색 입력에 글자를 넣으면 이름에 그 글자가 든 직원만 남는다. 검색은 `전체 직원` 그룹에만 걸리고
  `추가할 인원` 그룹은 항상 전부 보인다. 검색 결과가 없으면 `전체 직원` 그룹에 아무 행도 없다.
- 선택이 0명이면 확정 버튼은 `추가 완료` 이고 비활성(회색 배경 + 회색 글자)이다.
  1명 이상이면 `N명 추가` 로 바뀌고 활성(검은 배경 + 흰 글자)이다.
- `N명 추가` 클릭 → 선택한 직원들이 그 팀의 팀원 표 맨 아래에 붙고, 모달이 닫히며,
  `팀원 N명` 과 rail 의 `N명` 이 함께 늘어난다.
- `취소` / 딤 바깥 클릭 / `Escape` → 아무도 추가하지 않고 모달이 닫힌다. 선택은 남기지 않는다.

## 데이터

- 서버 데이터: 퍼블리싱 단계에서는 mock 으로 둔다(`/api` 스킬이 실제 연동을 담당).
  - 팀 목록 + 팀원: 쿼리키 후보 `['teams', 'list']`
  - 직원 목록(팀원 추가 모달): 쿼리키 후보 `['staff', 'list']`
  - 생성·수정·삭제·팀원 추가/제거는 mutation 후보이며, 퍼블리싱에서는 로컬 상태로 낙관적 갱신만 한다.
- 클라이언트 상태: 선택 팀 id, 팀명 수정 모드, 열린 모달, 모달 내 선택·검색어는
  페이지/모달 지역 상태로 관리한다. Zustand 는 쓰지 않는다.

## 비고 / 제약

- 이 화면의 버튼·검색 입력은 기존 `shared/ui` 의 `ActionButton`(radius 8) · `SearchBar`(radius 44, height 60) ·
  `SectionHeader`(`N건`) 과 규격이 다르다(radius 100 / radius 12·height 56 / `N명`).
  공용 컴포넌트를 바꾸면 다른 화면이 깨지므로 **이 화면 전용 styled 로 구현**하고,
  삭제 확인 모달·토스트만 공용을 재사용한다.
- 좌상단 햄버거(`icon / menu`)는 기존 `SidebarToggleButton` 이 담당하므로 새로 그리지 않는다.
- rail 은 높이가 고정이 아니라 내용에 따라 늘어난다(Figma 프레임마다 736/629/750 으로 다르다).
  좌우 패널은 같은 높이로 늘어난다(`align-items: stretch`).
- Figma 의 `Inter` 폰트는 디자인 파일 기본값 흔적이며, 구현은 저장소 공통 `Wanted Sans`(`theme.font.body`)를 쓴다.
- 스타일은 Emotion 을 사용한다. solid color/font family 는 theme 의미 토큰을 쓰고,
  px·rgba·spacing·radius 등 구현값은 styled 블록에 직접 작성한다.
- 신규 의미 토큰 후보(중간 게이트 확인 대상): `#111114` `#EEEEF1` `#ECECEF` `#FAFAFB` `#E5484D` `#F3C0C0` `#A1A1A9`.
