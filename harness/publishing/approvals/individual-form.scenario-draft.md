# Scenario Draft — individual-form

출처: `harness/publishing/specs/individual-form.spec.md` (행동명세가 source of truth)
기준 Figma: `yot`(`P7Jhnu8qV5m9q2QJNzkwAN`) `71:8747` / `84:8848` / `107:8848`
상태: draft — 게이트 ② 결정 반영(2026-09-15), 시나리오 승인 대기

전제:

- 데이터는 공통 fixture 를 쓴다 — 종 `1` 카피바라, 개체 `1` 동식이(수컷, 2019, 기타정보 `알락꼬리여우원숭이와 합사 중`, 사진 `동식이_2026.jpg`).
- 필수값 오류는 **인라인 오류 줄**이다(개발자 결정). 제출 시 전체를 검증해 실패한 모든 카드 아래에 줄을 보이고, 포커스는 옮기지 않는다.
- 생성 성공 토스트와 종 상세 개체 표 표시는 `species-detail` 이, 개체 상세 표시는 `individual-detail` 이 구현한다.

## 핵심 시나리오

### S1: 등록 화면 진입과 빈 폼
- Given: 종 `1` 이 존재한다
- When: `/species/1/individuals/create` 로 진입한다
- Then: 제목 `개체 등록`, 부제 `카피바라에 개체를 한 마리씩 등록합니다` 가 보이고, 개체명은 비어 있고, 성별 `암컷`·`수컷`·`미상` 은 모두 선택되지 않았고, 출생연도는 placeholder `0000` 과 접미사 `년` 을 보이고, 사진 칩은 없으며, 버튼 라벨은 `생성하기` 다

### S2: 성별 단일 선택
- Given: `/species/1/individuals/create` 화면
- When: 성별 `암컷` 을 클릭한 뒤 `미상` 을 클릭한다
- Then: 첫 클릭 후 `암컷` 만 선택되고, 두 번째 클릭 후 선택이 `미상` 으로 옮겨가 `암컷` 은 선택 해제된다

### S3: 출생연도 숫자 4자리 입력
- Given: `/species/1/individuals/create` 화면
- When: 출생연도에 `2019a7` 을 입력한다
- Then: 출생연도 값이 `2019` 가 된다

### S4: 사진 등록
- Given: 사진이 없는 등록 화면
- When: 드롭존으로 50MB 이하 jpg 이미지 한 장을 등록한다
- Then: 사진 카드에 그 파일명과 `${파일명} 다운로드`·`${파일명} 삭제` 컨트롤을 가진 칩 하나가 보인다

### S5: 사진 교체
- Given: 사진 칩이 하나 있는 등록 화면
- When: 드롭존으로 다른 png 이미지 한 장을 등록한다
- Then: 칩이 새 파일명으로 바뀌고 칩은 여전히 1개다

### S6: 개체 생성 성공
- Given: 개체명·성별·출생연도(`2022`)·사진을 모두 채운 등록 화면
- When: `생성하기` 를 클릭한다
- Then: 이탈 확인 없이 `/species/1` 로 이동하고 `데이터 생성에 성공했습니다` 토스트가 보이며, 종 상세 개체 표 첫 행(기본 최신순)에 새 개체명이 보인다

### S7: 기타정보 없이 생성
- Given: 기타정보만 비우고 나머지 필수값을 채운 등록 화면
- When: `생성하기` 를 클릭한다
- Then: 오류 줄 없이 생성되어 `/species/1` 로 이동한다

### S8: 수정 화면 진입과 값 복원
- Given: 개체 `1` 동식이가 종 `1` 에 존재한다
- When: `/species/1/individuals/1/edit` 로 진입한다
- Then: 제목 `개체 수정`, 부제 `카피바라 · 동식이의 정보를 수정합니다` 가 보이고, 개체명 `동식이`, 성별 `수컷` 선택, 출생연도 `2019`, 기타정보 `알락꼬리여우원숭이와 합사 중`, 사진 칩 `동식이_2026.jpg` 가 채워져 있으며, 버튼 라벨은 `저장하기` 다

### S9: 개체 수정 저장 성공
- Given: `/species/1/individuals/1/edit` 화면
- When: 개체명을 `동순이` 로 바꾸고 `저장하기` 를 클릭한다
- Then: 이탈 확인 없이 `/species/1/individuals/1` 로 이동하고 개체 상세에 `동순이` 가 보인다

### S10: 변경 없는 수정 화면 뒤로가기
- Given: 아무 값도 바꾸지 않은 `/species/1/individuals/1/edit` 화면
- When: `뒤로가기` 를 클릭한다
- Then: 이탈 확인 모달 없이 `/species/1/individuals/1` 로 이동한다

## 엣지 케이스

### S11: 개체명 미입력 검증
- Given: 개체명만 비우고 성별·출생연도·사진을 채운 등록 화면
- When: `생성하기` 를 클릭한다
- Then: 생성 요청 없이 개체명 카드 아래에 `개체명을 입력해주세요!` 오류 줄이 보이고, 포커스는 옮겨지지 않는다

### S12: 개체명 공백만 입력
- Given: 개체명에 공백만 입력하고 나머지 필수값을 채운 등록 화면
- When: `생성하기` 를 클릭한다
- Then: 생성 요청 없이 개체명 카드 아래에 `개체명을 입력해주세요!` 오류 줄이 보인다

### S13: 성별 미선택 검증
- Given: 성별만 선택하지 않은 등록 화면
- When: `생성하기` 를 클릭한다
- Then: 성별 카드 아래에 `성별을 선택해주세요!` 오류 줄이 보인다

### S14: 출생연도 미입력 검증
- Given: 출생연도만 비운 등록 화면
- When: `생성하기` 를 클릭한다
- Then: 출생연도 카드 아래에 `출생연도를 입력해주세요!` 오류 줄이 보인다

### S15: 출생연도 4자리 미만
- Given: 출생연도를 `201` 로 입력하고 나머지 필수값을 채운 등록 화면
- When: `생성하기` 를 클릭한다
- Then: 출생연도 카드 아래에 `올바른 출생연도를 입력해주세요!` 오류 줄이 보인다

### S16: 출생연도 범위 밖
- Given: 출생연도를 `1899` 로 입력하고 나머지 필수값을 채운 등록 화면
- When: `생성하기` 를 클릭한다(이어서 값을 `9999` 로 바꿔 다시 클릭한다)
- Then: 두 경우 모두 `올바른 출생연도를 입력해주세요!` 오류 줄이 보인다

### S17: 사진 미등록 검증
- Given: 사진만 등록하지 않은 등록 화면
- When: `생성하기` 를 클릭한다
- Then: 사진 카드 아래(드롭존 위)에 `사진을 등록해주세요!` 오류 줄이 보인다

### S18: 여러 항목이 비었을 때 오류 줄 동시 표시
- Given: 아무것도 입력하지 않은 등록 화면
- When: `생성하기` 를 클릭한다
- Then: `개체명을 입력해주세요!` · `성별을 선택해주세요!` · `출생연도를 입력해주세요!` · `사진을 등록해주세요!` 네 오류 줄이 각 카드 아래에 함께 보인다

### S19: 이미지가 아닌 파일 거부
- Given: 사진이 없는 등록 화면
- When: 드롭존으로 pdf 파일 한 개를 등록한다
- Then: 칩이 생기지 않고 `이미지 파일만 등록할 수 있습니다.` 문구가 보인다

### S20: 50MB 초과 이미지 거부
- Given: 사진이 없는 등록 화면
- When: 50MB 를 초과하는 jpg 파일을 등록한다
- Then: 칩이 생기지 않고 `<파일명>은 50MB를 초과해 첨부할 수 없습니다.` 문구가 보인다

### S21: 여러 이미지 동시 드롭 거부
- Given: 사진이 없는 등록 화면
- When: 이미지 두 장을 한 번에 드롭존에 끌어다 놓는다
- Then: 칩이 생기지 않고 `대표 사진은 1장만 등록할 수 있습니다.` 문구가 보인다

### S22: 입력 후 등록 화면 이탈 확인
- Given: 개체명을 입력한 등록 화면
- When: `뒤로가기` 를 클릭하고 이탈 확인 모달에서 `취소` 를 누른 뒤, 다시 `뒤로가기` 를 클릭하고 `확인` 을 누른다
- Then: `취소` 후에는 등록 화면과 입력한 개체명이 유지되고, `확인` 후에는 `/species/1` 로 이동한다

### S23: 빈 등록 화면 뒤로가기
- Given: 아무것도 입력하지 않은 등록 화면
- When: `뒤로가기` 를 클릭한다
- Then: 이탈 확인 모달 없이 `/species/1` 로 이동한다

### S24: 수정 중 사이드바 이동 이탈 확인
- Given: 성별을 `암컷` 으로 바꾼 `/species/1/individuals/1/edit` 화면
- When: 사이드바를 열어 `개체관리 > 개체 카드` 를 클릭한다
- Then: 이탈 확인 모달이 뜨고 `취소` 시 수정 화면과 바꾼 성별이 유지된다

### S26: 저장 실패 시 입력 보존
- Given: e2e 가짜 서버가 다음 개체 수정 요청에 500 을 주도록 한 `/species/1/individuals/1/edit` 화면에서 개체명을 바꾼 상태
- When: `저장하기` 를 클릭한다
- Then: URL 이 `/species/1/individuals/1/edit` 로 유지되고 바꾼 입력이 그대로 있으며 `저장하지 못했습니다. 다시 시도해 주세요.` 가 보이고 버튼이 다시 활성화된다

### S27: 없는 종으로 등록 진입
- Given: id `999` 인 종이 없다
- When: `/species/999/individuals/create` 로 진입한다
- Then: 폼 대신 `종을 찾을 수 없습니다.` 와 `/species` 로 가는 `목록으로 돌아가기` 링크가 보인다

### S28: 없는 개체로 수정 진입
- Given: 종 `1` 에 id `999` 인 개체가 없다
- When: `/species/1/individuals/999/edit` 로 진입한다
- Then: 폼 대신 `개체를 찾을 수 없습니다.` 와 `/species/1` 로 가는 `종 상세로 돌아가기` 링크가 보인다

### S29: 키보드만으로 등록
- Given: `/species/1/individuals/create` 화면
- When: 키보드만으로 개체명 입력 → 성별 화살표 키 선택 → 출생연도 입력 → 기타정보 입력 → `사진 업로드` 버튼으로 파일 선택 → `생성하기` 를 수행한다
- Then: 모든 조작이 가능하고 생성 후 `/species/1` 로 이동한다
