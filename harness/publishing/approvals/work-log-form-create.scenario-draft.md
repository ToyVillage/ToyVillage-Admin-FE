# Scenario Draft — work-log-form-create

출처: `harness/publishing/specs/work-log-form-create.spec.md` (행동명세가 source of truth)
상태: draft (게이트 승인 전)

## 핵심 시나리오

### S1: 생성 화면 진입
- Given: 양식 목록(`/work-logs?tab=forms`)
- When: `양식 생성하기` 클릭 → `/work-logs/forms/create`
- Then: 1단계 활성 스텝 인디케이터(`1단계 항목 설정`), `뒤로가기`, `양식명 *` 카드,
  빈 질문 카드 2개, `항목 추가하기`, `다음`이 보인다

### S2: 항목 추가
- Given: 1단계, 질문 카드 2개
- When: `항목 추가하기` 클릭
- Then: 질문 카드가 3개가 되고 새 카드의 질문명에 포커스가 간다

### S3: 항목 삭제
- Given: 1단계, 질문 카드 3개
- When: 두 번째 카드의 휴지통 클릭
- Then: 질문 카드가 2개가 된다

### S4: 유형 드롭다운
- Given: 1단계, 유형이 `선택`인 질문 카드
- When: 유형 셀렉트 클릭
- Then: `주관식`, `객관식 질문`, `체크박스`, `파일 업로드` 4개가 보인다

### S5: 유형 선택
- Given: S4 의 드롭다운이 열린 상태
- When: `객관식 질문` 클릭
- Then: 드롭다운이 닫히고 배지가 `객관식 질문 *`으로 바뀌며 `옵션 추가` 행이 보인다

### S6: 선택지 추가
- Given: 유형이 `객관식 질문`이고 선택지가 없는 카드
- When: `옵션 추가` 클릭
- Then: 빈 선택지 행 1개가 생기고 추가 행이 `옵션 추가 또는 기타 추가`로 바뀐다

### S7: 기타 추가
- Given: 선택지가 1개 이상인 `객관식 질문` 카드
- When: `기타 추가` 클릭
- Then: `기타:` 행이 추가되고 `기타 추가` 가 더 이상 보이지 않는다

### S8: 선택지 삭제
- Given: 선택지가 2개인 카드
- When: 첫 선택지 행의 X 클릭
- Then: 선택지가 1개가 된다

### S9: 양식명 미입력 검증
- Given: 1단계, 양식명이 비어 있음
- When: `다음` 클릭
- Then: 양식명 카드에 빨간 테두리와 `양식명을 입력해주세요!`가 보이고 2단계로 넘어가지 않는다

### S10: 질문명 미입력 검증
- Given: 1단계, 양식명은 채웠고 질문명이 빈 카드가 있음
- When: `다음` 클릭
- Then: 그 카드에 빨간 테두리와 `해당 항목을 입력해주세요!`가 보이고 2단계로 넘어가지 않는다

### S11: 2단계 진입
- Given: 1단계 필수값을 모두 채운 상태
- When: `다음` 클릭
- Then: `구역 번호 설정` 카드가 보이고 스텝 인디케이터가 2단계 활성이 된다

### S12: 2단계에서 1단계로 복귀
- Given: 2단계
- When: `뒤로가기` 클릭
- Then: 1단계로 돌아가고 입력했던 양식명·질문이 그대로 남아 있다

### S13: 구역 자동 생성
- Given: 2단계, 설정된 구역 0개
- When: 접두 `A`, 시작 `1`, 끝 `3`으로 `생성` 클릭
- Then: 칩 `A1`, `A2`, `A3` 이 보이고 `설정된 구역 (3)` 이 된다

### S14: 구역 직접 추가
- Given: 2단계
- When: `직접 추가` 입력에 `기타` 를 넣고 `추가` 클릭
- Then: 칩 `기타` 가 추가되고 입력이 비워진다

### S16: 구역 개별 삭제
- Given: 칩이 3개 있는 2단계
- When: 첫 칩의 X 클릭
- Then: 그 칩이 사라지고 `설정된 구역 (2)` 가 된다

### S18: 구역 미설정 검증
- Given: 2단계, 설정된 구역 0개
- When: `생성하기` 클릭
- Then: `구역 번호를 설정해주세요` 모달이 보이고 생성 요청이 가지 않는다

### S19: 생성 성공
- Given: 1단계를 채우고 구역이 1개 이상인 2단계
- When: `생성하기` 클릭
- Then: 생성 요청이 한 번 전송되고 `/work-logs?tab=forms` 로 이동한다

### S20: 1단계에서 목록 복귀
- Given: 아무것도 입력하지 않은 1단계
- When: `뒤로가기` 클릭
- Then: 모달 없이 `/work-logs?tab=forms` 로 이동한다

### S25: 입력 후 나가기 확인
- Given: 양식명을 입력한 1단계
- When: `뒤로가기` 클릭
- Then: `정말 나가시겠습니까?` 모달이 보이고, `확인` 클릭 시 `/work-logs?tab=forms` 로 이동한다

## 엣지 케이스

### S15: 중복 구역 추가 차단
- Given: 칩 `A1` 이 이미 있는 2단계
- When: `직접 추가` 에 `A1` 을 넣고 `추가` 클릭
- Then: 칩이 늘지 않는다

### S17: 구역 전체 삭제
- Given: 칩이 3개 있는 2단계
- When: `전체 삭제` 클릭 → `정말 삭제하시겠습니까?` 모달의 `확인` 클릭
- Then: 칩이 모두 사라지고 `설정된 구역 (0)` 이 된다

### S24: 전체 삭제 취소
- Given: 칩이 3개 있는 2단계
- When: `전체 삭제` 클릭 → 모달의 `취소` 클릭
- Then: 칩 3개가 그대로 남는다

### S21: 키보드 조작
- Given: 마우스를 쓰지 않는 사용자
- When: Tab / 방향키 / Enter 만 사용
- Then: 양식명 입력, 질문명 입력, 유형 선택, 선택지 추가, 구역 추가, 생성을 모두 수행할 수 있다

### S22: 잘못된 자동 생성 범위
- Given: 2단계
- When: 시작 `5`, 끝 `3` 으로 `생성` 클릭
- Then: 칩이 추가되지 않는다

### S23: 유형 변경 시 선택지 정리
- Given: 선택지 2개가 있는 `객관식 질문` 카드
- When: 유형을 `주관식` 으로 변경
- Then: 선택지 목록이 사라지고 밑줄 `텍스트` 자리가 보인다

### S26: 파일 업로드 유형의 답변 영역
- Given: 1단계의 질문 카드
- When: 유형을 `파일 업로드` 로 선택
- Then: `클릭하거나 파일을 끌어다 놓으세요` 와
  `JPG · PNG · PDF · 최대 10MB · 최대 5개` 가 보인다

### S27: 객관식·체크박스는 빈 선택지 하나로 시작한다
- Given: 유형이 `선택` 인 질문 카드
- When: 유형을 `객관식 질문` / `체크박스` 로 고름
- Then: 빈 선택지 한 줄이 이미 놓여 있다

### S28: 새로 추가한 선택지에 바로 입력할 수 있다
- Given: `객관식 질문` 카드
- When: `옵션 추가` 클릭
- Then: 새 선택지에 포커스가 가 있어 그대로 타이핑된다

### S29: 기타 행에는 입력란이 없다
- Given: `객관식 질문` 카드
- When: `기타 추가` 클릭
- Then: `기타:` 행에는 입력란이 없고 응답자가 적을 밑줄 자리만 보인다

### S30: 기타는 항상 선택지보다 아래에 있다
- Given: `기타:` 행이 있는 카드
- When: `옵션 추가` 클릭
- Then: 새 선택지가 기타 행보다 위에 놓인다

### S31: 단계가 URL 로 바뀐다
- Given: 1단계를 채운 상태
- When: `다음` 클릭 → 브라우저 뒤로가기
- Then: URL 이 `/zones` 로 갔다가 1단계로 돌아오고 입력값이 남아 있다

### S32: 항목이 하나도 없으면 다음으로 넘어가지 않는다
- Given: 양식명만 채우고 질문 카드를 모두 지운 1단계
- When: `다음` 클릭
- Then: `해당 항목을 입력해주세요!` 가 보이고 2단계로 넘어가지 않는다

### S33: 자동 생성 번호는 숫자만 입력된다
- Given: 2단계
- When: 시작·끝 번호에 문자가 섞인 값을 입력
- Then: 숫자만 남는다

### S34: 브라우저 뒤로가기에도 나가기 확인이 뜬다
- Given: 목록에서 들어와 양식명을 입력한 1단계
- When: 브라우저 뒤로가기
- Then: `정말 나가시겠습니까?` 모달이 뜨고, `확인` 하면 목록으로 나간다

### S35: 1단계 없이 2단계 URL 로 들어오면 1단계로 되돌린다
- Given: 새로고침이나 링크로 `/work-logs/forms/create/zones` 에 바로 진입
- When: 화면이 열림
- Then: 1단계로 되돌아간다(1단계 값 없이는 저장할 수 없다)

### S36: 자동 생성 범위가 너무 크면 아무것도 만들지 않는다
- Given: 2단계
- When: 시작 `1`, 끝 `99999999999` 로 `생성` 클릭
- Then: 구역이 만들어지지 않는다(한 번에 만들 수 있는 수에 상한이 있다)
