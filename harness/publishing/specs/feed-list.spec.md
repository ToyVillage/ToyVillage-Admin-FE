## 목적

운영 관리자가 특정 날짜의 먹이 급여 내역을 개체 분류(포유류·파충류·조류·어류)별로 조회한다.
행을 눌러 개별 급여 기록의 상세로 들어간다.

## 범위

- 포함: 조회날짜 필터, 분류 탭, 급여 내역 표, 페이지네이션, 행 클릭 이동, 사이드바 항목 라우트 연결
- 제외: 실제 API 연동(`/api` 스킬 담당), 급여 기록 생성·수정·삭제, 검색·정렬, 내역 내보내기

## 라우트와 진입

- `/feeds` → 먹이 급여 관리 목록을 표시한다.
- 행 클릭 → `/feeds/:id` 로 이동한다. `:id` 는 **급여 기록 id** 다(개체 id 가 아니다).
- 사이드바 `먹이 급여 관리` 항목의 이동 대상을 `/feeds` 로 지정한다.
  사이드바 자체의 동작 계약은 `harness/publishing/specs/sidebar.spec.md` 를 따르며 이 spec 은 `to` 지정만 한다.

## 동작 (behavioral spec — source of truth)

- 화면 진입 → 제목 `먹이 급여 관리`, 부제 `포유류·파충류·조류·어류별 먹이 급여 내역`,
  `조회날짜` 필터, `전체` 탭 활성, 1페이지 목록이 보인다.
- 조회날짜의 초기값은 오늘 날짜(년·월·일)다.
- 조회날짜 년/월/일 드롭다운의 동작은 업무일지관리 목록과 동일하다.
  - 각 드롭다운 클릭 → 그 드롭다운이 열린다. 다른 드롭다운을 열면 앞서 열린 드롭다운은 닫힌다.
  - 항목 클릭 → 값이 선택되고 드롭다운이 닫히며, 목록이 그 날짜 기준으로 다시 걸러지고 1페이지로 리셋된다.
  - 바깥 클릭 또는 `Escape` → 드롭다운이 닫히고 선택은 바뀌지 않는다.
  - 년 선택지는 현재 연도 기준 최근 5개 연도(내림차순), 월은 1~12월, 일은 선택된 년·월의 실제 일수만큼이다.
    년 또는 월을 바꿔 선택된 일이 그 달에 없으면 그 달의 마지막 날로 보정한다.
- 분류 탭은 `전체` `포유류` `파충류` `조류` `어류` 다.
  탭 클릭 → 그 분류의 급여 내역만 남고 1페이지로 리셋된다. `전체` 는 모든 분류를 보여준다.
  조회날짜 선택값은 탭을 바꿔도 유지된다.
- 표의 열은 `대상 개체` / `먹이 종류 · 급여량` / `급여자` / `급여일시` 다.
  - `대상 개체` 는 `<종> · <개체명>` 형식이다(예: `표범 · 레오`).
  - `먹이 종류 · 급여량` 은 `<먹이 종류> <급여량>` 형식이다(예: `생닭 1.2kg`).
  - `급여일시` 는 `YYYY.MM.DD HH:mm` 형식이다.
- 행 클릭 → `/feeds/:id` 로 이동한다.
- 한 페이지는 4행이다. 페이지 번호 클릭 → 해당 페이지 행으로 바뀐다.
  `이전 페이지` / `다음 페이지` 는 한 페이지씩 이동하며, 1페이지에서 `이전 페이지`,
  마지막 페이지에서 `다음 페이지` 는 비활성이다.
- 선택한 조회날짜·분류에 급여 내역이 없으면 → 행 대신 `해당 날짜에 급여 내역이 없습니다.` 를 표시하고
  페이지네이션을 숨긴다. (Figma 에 빈 상태 프레임이 없어 업무일지관리 목록의 빈 상태 규약을 따랐다 —
  중간 게이트에서 문구를 확정한다.)
- 로딩 중에는 같은 자리에 빈 표를 두어 레이아웃이 튀지 않게 한다(빈 상태 문구는 쓰지 않는다).

## 데이터

- 서버 데이터: 퍼블리싱 단계에서는 mock 으로 둔다(`/api` 스킬이 실제 연동을 담당).
  - 급여 내역 목록: 쿼리키 후보 `['feeds', 'list', { date, species }]`
- 클라이언트 상태: 조회날짜·분류 탭·페이지는 컴포넌트 지역 상태로 관리한다. Zustand 는 쓰지 않는다.

## 컴포넌트 구조/props

- `FeedListPage` — `/feeds` 화면. 조회날짜·분류 탭·페이지 상태를 소유한다.
- `FeedTable { feeds, onRowClick, pagination, emptyLabel }` (entities/feed/ui) — 급여 내역 표.
  `shared/ui` 의 `DataTable` 을 래핑하고 도메인 → row 매핑만 담당한다.
- 조회날짜 필터는 업무일지관리의 `WorkLogDateFilter` 와 동작·모양이 같다.
  공용 `DateFilter`(shared/ui) + 공용 달력 날짜 헬퍼(shared/lib)로 승격해 양쪽이 재사용한다.
  → 새 shared 컴포넌트이므로 중간 게이트 승인 대상이다.
- 분류 탭은 기존 `shared/ui` 의 `CategoryTabs` 를 재사용한다.

## 비고 / 제약

- Figma 우상단 `내역 내보내기` 버튼(`1:10456`)과 각 행의 케밥 버튼(`453:13587` 등)은
  `_mask-export-btn` / `_mask-kebab1~4` 흰 사각형으로 덮여 있다. **구현하지 않는다.**
- 케밥 열이 사라졌으므로 `급여일시` 열이 표 오른쪽 남는 폭을 채운다.
  열 폭은 `대상 개체` 240 / `먹이 종류 · 급여량` 480 / `급여자` 280 / `급여일시` 나머지다.
- 표 행 구분선 색은 `#848491`(`colors.textGuide`)이다. 업무 표의 기본 구분선(`#727272`)과 다르다.
- 스타일은 Emotion 을 사용한다. solid color/font family 는 theme 의미 토큰을 쓰고,
  px·rgba·spacing·radius 등 구현값은 styled 블록에 직접 작성한다.
