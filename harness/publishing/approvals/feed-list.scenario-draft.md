# Scenario Draft — feed-list

출처: `harness/publishing/specs/feed-list.spec.md` (2026-10-28 4층·5층 수정안)
상태: draft (게이트 승인 전)

## 핵심 시나리오

### S1: 목록 진입 기본 표시
- Given: 오늘 4층 급여 기록이 12건 있다.
- When: `/feeds` 로 진입한다.
- Then: 제목 `먹이 급여 관리`, 부제 `4층·5층별 먹이 급여 내역`, `조회날짜` 드롭다운, 층 탭 `4층`(선택)·`5층` 이 보이고
  표 머리 열이 `일반명` `개체명` `급여시간` `먹이 종류` `급여량` `잔량` `특이사항` `급여자` 순서이며 1페이지 10행이 보인다.
  `전체`·`포유류` 같은 분류 탭과 `종`·`급여날짜` 열은 없다.

### S2: 4층 행 값 표시
- Given: 4층 기록에 `GML` 150·잔량 20·특이사항 없음, `KGL` 1.2·잔량 없음 기록이 있다.
- When: `/feeds` 를 연다.
- Then: 급여시간은 `HH:mm`, 급여량은 `150 g/ml`·`1.2 kg/l`, 잔량은 `20 g/ml`·`-`, 특이사항 없음은 `-` 로 보인다.

### S3: 5층 탭으로 바꾸기
- Given: `/feeds` 2페이지를 보고 있다.
- When: `5층` 탭을 누른다.
- Then: URL 에 `floor=5` 가 남고 1페이지로 돌아가며, 표 머리 열이 `일반명` `개체명` `먹이 종류` `급여량` `급여자` 순서인 5층 행이 보인다.

### S4: 조회날짜 바꾸기
- Given: 5층 탭 2페이지다.
- When: `일` 드롭다운에서 다른 날을 고른다.
- Then: 드롭다운이 닫히고 그 날짜의 5층 1페이지가 보이며 URL `date` 가 바뀌고 층은 5층 그대로다.

### S5: 페이지네이션
- Given: 4층 기록이 12건이다.
- When: `다음 페이지` 를 누르고 다시 `이전 페이지` 를 누른다.
- Then: 2페이지에 2행이 보이고 URL 에 `page=2` 가 남으며, 1페이지에서는 `이전 페이지`, 마지막 페이지에서는 `다음 페이지` 가 비활성이다.

### S6: 행 클릭 이동
- When: 4층 행을 누른다 / 5층 행을 누른다.
- Then: 각각 `/feeds/<id>`, `/feeds/fifth-floor/<id>` 로 이동한다.

### S7: 행 케밥 메뉴
- When: 한 행의 케밥을 연 뒤 다른 행 케밥을 열고, Escape 를 누른다.
- Then: `수정`·`삭제` 메뉴가 한 번에 하나만 열리고 Escape 로 닫히며 행 이동은 일어나지 않는다.

### S8: 케밥 수정
- When: 4층 행 케밥 `수정` / 5층 행 케밥 `수정` 을 누른다.
- Then: 각각 `/feeds/<id>/edit`, `/feeds/fifth-floor/<id>/edit` 로 이동한다.

### S9: 케밥 삭제 성공
- When: 케밥 `삭제` → 확인 모달 `확인`.
- Then: 모달이 닫히고 그 행이 사라지며 `데이터 삭제에 성공했습니다` 토스트가 보인다.

## 엣지 시나리오

### S10: 삭제 취소·실패
- When: 확인 모달에서 `취소` 를 누른다 / 삭제가 실패한다.
- Then: 취소면 행이 그대로이고 초점이 그 케밥으로 돌아온다. 실패면 `데이터 삭제에 실패했습니다` 토스트가 보이고 행은 그대로다.

### S11: 빈 날짜
- Given: 고른 날짜·층에 기록이 없다.
- Then: 행 대신 `해당 날짜에 급여 내역이 없습니다.` 가 보이고 페이지네이션이 없다.

### S12: 조건 유지와 잘못된 쿼리
- When: `/feeds?date=<날짜>&floor=5&page=2` 를 새로고침한다 / `/feeds?floor=7&page=x&date=bad` 로 들어온다.
- Then: 새로고침 뒤에도 같은 날짜·5층·2페이지다. 잘못된 쿼리는 오늘·4층·1페이지로 본다.

### S13: 조회 실패
- Given: 목록 조회가 실패한다.
- Then: `급여 내역을 불러오지 못했습니다. 다시 시도해 주세요.` 상태 카드가 보인다.
