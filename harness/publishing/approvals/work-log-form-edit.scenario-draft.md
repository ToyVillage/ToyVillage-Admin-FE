# Scenario Draft — work-log-form-edit

출처: `harness/publishing/specs/work-log-form-edit.spec.md` (행동명세가 source of truth)
상태: draft (게이트 승인 전)

생성 화면과 공통인 조작(항목 추가·삭제, 유형 선택, 선택지 편집, 구역 자동 생성)은
`work-log-form-create.scenario-draft.md` 가 덮는다. 여기에는 **수정 전용 동작**만 둔다.

## 핵심 시나리오

### S1: 수정 화면 진입
- Given: 등록된 양식이 있는 목록(`/work-logs?tab=forms`)
- When: 케밥 메뉴 `수정` 클릭 → `/work-logs/forms/:id/edit`
- Then: 1단계 활성 스텝 인디케이터, 기존 양식명, 기존 질문 카드, `다음`, `저장하기` 가 보인다

### S2: 기존 값 표시
- Given: S1 의 수정 화면
- When: 화면을 본다
- Then: 각 질문 카드에 저장된 질문명·유형 배지·선택지가 그대로 보인다

### S3: 변경 없이 나가기
- Given: 값을 하나도 고치지 않은 수정 1단계
- When: `뒤로가기` 클릭
- Then: 모달 없이 `/work-logs?tab=forms` 로 이동한다

### S4: 변경 후 나가기 확인 모달
- Given: 양식명을 고친 수정 1단계
- When: `뒤로가기` 클릭
- Then: `정말 나가시겠습니까?` 와 `저장하지 않고 돌아갈 시 입력된 정보가 삭제됩니다` 가 보인다

### S5: 나가기 취소
- Given: S4 의 모달
- When: `취소` 클릭
- Then: 모달이 닫히고 수정 화면과 고친 값이 그대로 남는다

### S6: 나가기 확인
- Given: S4 의 모달
- When: `확인` 클릭
- Then: `/work-logs?tab=forms` 로 이동한다

### S7: 1단계 저장 검증
- Given: 양식명을 비운 수정 1단계
- When: `저장하기` 클릭
- Then: `양식명을 입력해주세요!` 가 보이고 저장 요청이 가지 않는다

### S8: 1단계 → 2단계
- Given: 수정 1단계
- When: `다음` 클릭
- Then: 2단계가 보이고 저장되어 있던 구역이 칩으로 채워져 있다

### S9: 저장된 구역 삭제 확인 모달
- Given: 저장되어 있던 칩이 있는 수정 2단계
- When: 그 칩의 X 클릭
- Then: `정말 삭제하시겠습니까?` 와 `삭제하신 뒤에는 영구삭제되며 복구 할 수 없습니다` 가 보인다

### S10: 구역 삭제 취소·확인
- Given: S9 의 모달
- When: `취소` 클릭 → 다시 X 클릭 후 `확인` 클릭
- Then: `취소` 뒤에는 칩이 남고, `확인` 뒤에는 칩이 사라진다

### S17: 수정에서 항목 추가
- Given: 수정 1단계
- When: `항목 추가하기` 클릭
- Then: 빈 질문 카드가 맨 아래에 하나 추가된다

### S13: 저장 성공
- Given: 필수값이 유효하고 구역이 1개 이상인 수정 화면
- When: `저장하기` 클릭
- Then: 저장 요청이 한 번 전송되고 `/work-logs?tab=forms` 로 이동한다

## 엣지 케이스

### S11: 새로 추가한 구역은 확인 없이 삭제
- Given: 이번 편집에서 방금 `추가` 한 칩
- When: 그 칩의 X 클릭
- Then: 모달 없이 바로 사라진다

### S12: 구역을 모두 지우고 저장
- Given: 구역을 전부 지운 수정 2단계
- When: `저장하기` 클릭
- Then: `구역 번호를 설정해주세요` 모달이 보이고 저장되지 않는다

### S14: 저장 실패
- Given: 서버가 저장을 거부하는 상황
- When: `저장하기` 클릭
- Then: 입력값과 현재 단계가 유지되고 다시 저장할 수 있다

### S15: 삭제된 양식 수정 진입
- Given: 목록에서 삭제된 양식의 id
- When: `/work-logs/forms/:id/edit` 로 진입
- Then: `/work-logs?tab=forms` 로 되돌아간다

### S16: 키보드 조작
- Given: 마우스를 쓰지 않는 사용자
- When: Tab / 방향키 / Enter / Escape 만 사용
- Then: 값 수정, 단계 이동, 모달 확인·취소, 저장을 모두 수행할 수 있다

### S18: 수정도 브라우저 뒤로가기에서 나가기 확인이 뜬다
- Given: 목록에서 들어와 양식명을 고친 수정 1단계
- When: 브라우저 뒤로가기
- Then: `정말 나가시겠습니까?` 모달이 뜬다
