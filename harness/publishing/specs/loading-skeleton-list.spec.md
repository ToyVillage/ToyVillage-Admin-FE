# 로딩 스켈레톤 · 목록 행동명세

## 목적

목록형 화면과 대시보드가 첫 조회 중일 때 빈 표나 "불러오는 중" 문구 대신 Figma `스켈레톤 · 목록`(`2021:24413`) 모양의 스켈레톤을 보인다. 이슈 #108의 1차 범위(공통 컴포넌트 + 목록)다.

## 동작 (source of truth)

- 화면의 첫 목록 조회가 끝나기 전에는 해당 화면의 스켈레톤을 보인다.
  - 스켈레톤 루트는 `role="status"`, `aria-busy="true"`, 접근 이름 `불러오는 중`을 가진다.
  - 스켈레톤 안의 막대는 스크린리더에 읽히지 않는다(`aria-hidden`).
- 조회가 성공하면 스켈레톤이 사라지고 실제 목록이 보인다.
- 조회가 실패하면 스켈레톤이 사라지고 기존 오류 표시를 그대로 보인다.
- 이미 데이터를 가진 상태의 재조회(검색·탭·페이지 이동으로 인한 placeholder 유지)에는 스켈레톤을 다시 보이지 않는다. 기존 동작 유지.

## 데이터

- 서버 데이터: 기존 TanStack Query 조회의 `isPending`만 사용한다. 새 API 연결 없음.

## 컴포넌트 구조/props

- `Skeleton` (shared/ui) — 막대 1개. `width`, `height`, `radius?`(기본 pill). Figma 채움: `#DBDBDB` 선형 그라데이션(알파 0.05 → 1, 0~50%).
- `SkeletonStatus` (shared/ui) — 스켈레톤 루트. `role="status"`, `aria-busy`, `aria-label="불러오는 중"`.
- 화면별 스켈레톤 레이아웃은 기존 레이아웃 컴포넌트(PageHeader 영역·카드·표 헤더 등)의 치수를 따라 각 page(또는 page/ui)에 둔다. 표 형태는 공용 `TableSkeleton { columns, rows }`로 묶는다.
